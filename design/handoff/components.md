# Компоненты

Соглашения: размеры и цвета — только из `tokens.css`. Все интерактивные элементы
имеют видимый фокус `outline: 2px solid var(--accent)` (`outline-offset: 1px`,
внутри строки `-2px`). Иконки — `lucide-react`, 16px, `strokeWidth={1.5}`.

## Оболочка

### AppShell
Сетка: `TopBar 44` / (`StageRail 56` + контент) / `StatusBar 24`.
Пропсы: `episode`, `channel`, `stage`, `spend`.

### TopBar — 44px
Слоты слева направо: логотип (ссылка на «Выпуски») · ChannelSwitcher ·
название выпуска (инлайн-переименование по клику) · SaveIndicator ·
SpendMeter · кнопка «?» · кнопка настроек.
Состояния: выпуск открыт / не открыт (тогда вместо названия «Выпуск не открыт»).

### StageRail — 56px
6 этапов: Идея, Сценарий, Генерация, Монтаж, Экспорт, Публикация.
Состояния этапа: `todo` (иконка `--text-disabled`, полый маркер) ·
`active` (заливка `--accent`, ink чёрный) · `done` (сплошной маркер `--text-primary`) ·
`error` (маркер-квадрат `--status-failed`).
Появляется только когда выпуск открыт. Все этапы кликабельны, недоступные — для просмотра.

### StatusBar — 24px
Левый блок: что происходит сейчас (при процессе — глиф штриховки + этап и процент).
Средний: предупреждение или пояснение. Правый: 2–3 горячие клавиши.

### PanelHeader — 28px
`title` 13/600 + `note` 12 secondary + правый слот. Фон `--bg-strip`, нижняя граница `--line`.

## Контролы

### Button
Высота 28 (компакт 24), радиус 4, паддинг 0 12, 13/500, gap 6.
Варианты:
- `primary` — заливка `--accent`, ink `--accent-ink`; hover/pressed — `--accent-hover` / `--accent-pressed`. **Один на экран.**
- `secondary` — `--bg-raised` + граница `--line`; hover — граница `--line-strong`.
- `ghost` — без фона; hover `#ffffff0A`, текст `--text-primary`.
- `danger` — контур `--status-failed`, текст `--status-failed-text`; hover — заливка `#BB3E031F`.
- `statusOutline` — контур и текст в цвете статуса (кнопка действия в карточке ошибки).
Состояния: default · hover · active · focus · disabled (`--bg-raised` + `--text-disabled`) ·
loading (нижняя кромка 2px штриховкой, текст меняется на состояние: «Генерирую 14 из 24»).
Пропсы: `variant`, `size`, `icon`, `price` (рендерится в подпись: `«…(~$1.61)»`), `loading`, `disabled`.

### IconButton — 24×24, радиус 4, иконка 16. Всегда `title`. Варианты: ghost, danger-hover.

### Input / Textarea / NumberInput
Высота 28, `--bg-raised`, граница `--line`, радиус 4, текст 13, паддинг 8.
Фокус — граница `--accent` + ринг. Ошибка — граница `--status-failed`, подпись 11 `--status-failed-text`.
Textarea промпта — `--font-script` 12/18, авторост до 6 строк.
NumberInput — `--font-dense`, выравнивание по правому краю, суффикс единицы 11 secondary.

### Select — поле + шеврон. Меню: `--bg-raised`, граница `--line`, радиус 6, тень `--shadow-overlay`,
строки 28, выбранное помечено галочкой `--accent` (не заливкой строки).

### SegmentedControl — 28 (компакт 24)
Контейнер `--bg-raised` + граница `--line`, радиус 4, внутренний отступ 2, зазор между сегментами 2.
Сегмент: высота 22 (компакт 18), паддинг 0 12, 12/500, радиус 3; активный — фон `--line` и `--text-primary`,
остальные — `--text-secondary`, hover `--text-primary`. 2–4 коротких варианта. ←→ Home End переключают сразу.
Это и фильтр («Все / Cursus / Otto»), и переключатель вида в заголовке экрана («Тренды / Референс»,
«Сценарий / План кадров / JSON», «Стиль / Периоды / Персонажи»).

### Slider + NumberInput (одна строка)
Рельс 2px `--line`, заполнение `--accent`, ручка 12×12 радиус 2.
Дополнительно: `defaultTick` (засечка значения пресета/голоса, цвет `--accent-deep`),
`spread` (набор засечек `--line-strong` — разброс значений в мультивыделении).
Клавиши ←→, ×10 с Shift, ⌥-клик возвращает к дефолту.

### Toggle — 32×18, knob 12. On — `--accent` + чёрный knob, off — `--line` + серый knob.

### Checkbox / Radio — 14×14. Checkbox on — заливка `--accent` + чёрная галочка;
indeterminate — чёрная черта. Radio on — граница `--accent` + точка 7px.

### Chip — 22–24px, радиус 4. Варианты: `filter` (вкл — заливка `--accent`, ink чёрный),
`tag` (с кнопкой удаления), `add` (пунктирная граница).

### StatusBadge / StatusGlyph
Пять статусов, форма обязательна: queued — полый круг · generating — штриховка 45° ·
ready — сплошная точка · warning — треугольник · failed — квадрат с крестом.
`StatusBadge` = глиф + подпись 11/500 в парном светлом цвете; в таблицах — только глиф 16px.

### Toast
Внизу справа, `--bg-raised`, граница `--line`, левая полоса 2px в цвете статуса,
радиус 6, тень `--shadow-overlay`, 13/400, автоскрытие 4 с, действие «Отменить» внутри.
Текст — совершённое действие («Перерисовано»). Стек до 3, дальше «и ещё 2».

### Dialog / Overlay
Скрим `--scrim`, карточка `--bg-panel` + граница `--line`, радиус 6, тень `--shadow-dialog`,
шапка 36, подвал 48. `HotkeysOverlay` открывается по «?», закрывается по «?» и Esc.

### Tooltip
Подсказка к одному интерактивному элементу: по наведению — через 300 мс, по фокусу — сразу; Esc закрывает.
`--bg-raised`, граница `--line`, радиус 4, паддинг 4 8, 12/400 `--text-primary`, тень `--shadow-overlay`,
ширина до 256. Над якорем или под ним, по левому краю. Только текст, без действий.

### Popover
Немодальный слой у якоря: небольшие формы и списки выбора (переключатель канала, меню слота).
`--bg-raised`, граница `--line`, радиус 6, паддинг 12, тень `--shadow-overlay`, ширина от 192. При открытии
фокус — на первый интерактивный элемент внутри; Esc и клик вне закрывают, фокус возвращается на якорь.

### DropdownMenu
Меню действий; в отличие от Select ничего не хранит. Триггер — secondary-кнопка с подписью и шевроном или
IconButton 24×24 с `title`. Меню: `--bg-raised`, граница `--line`, радиус 6, тень `--shadow-overlay`, паддинг 4 0,
ширина от 176. Пункт 28, паддинг 0 8, 13/400, иконка 16 `--text-secondary`, справа — KeyHint сочетания;
hover и фокус — `--bg-hover`; `danger` — текст `--status-failed-text`, hover `--surface-failed`; выключенный —
`--text-disabled`; разделитель 1px `--rule-inner`, отступы 4. Клавиши: ↓ Enter Space открывают на первом пункте,
↑ — на последнем; ↑↓ Home End — по пунктам; Enter Space — выбор; Esc и Tab закрывают с возвратом фокуса на триггер.

### Tabs
Вкладки внутри панели; содержимое — TabPanel. Высота 28, вкладка — паддинг 0 12, 13/500. Выбранная —
`--text-primary` и нижняя полоса 2px `--accent`; остальные — `--text-secondary`, hover `--text-primary`;
выключенная — `--text-disabled`. Нижняя граница списка `--line` (в заголовке экрана её нет — там уже есть своя).
←→ Home End переключают сразу. Переключатель вида в заголовке экрана — SegmentedControl, не Tabs.

### ProgressBar
`sm` 2px — карточки и строки, `md` 4px — ProcessCard. Трек `--line`, радиус 2. Заливка по статусу:
generating — бегущая штриховка 45°, как у глифа; ready — `--accent`; warning — `--status-warning`;
failed — `--status-failed`. Неизвестный процент — штриховка на всю ширину.

### Skeleton
Заглушка загрузки: `--bg-raised` с пульсацией, без неё при reduced motion. Повторяет форму будущего содержимого:
`text` — строки 12 через 8, последняя на 2/3 ширины; `block` — прямоугольник с радиусом 4; `circle` — аватар
или глиф. Ошибка загрузки — ErrorCard, не вечный скелетон.

### Divider
Линия 1px: `--line` между зонами и панелями, `--rule-inner` внутри карточки. Горизонтальная или вертикальная,
на всю высоту родителя.

### ScrollArea
Прокручиваемая область (вертикально, горизонтально или обе оси) с тонким скроллбаром: 9px, бегунок `--line`,
радиус 5. Область с подписью получает фокус с клавиатуры, стрелки её прокручивают.

### KeyHint
Сочетание клавиш: каждая клавиша — отдельный чип, шрифт `--font-dense`, радиус 2, после чипов — подпись
11 `--text-secondary`. `sm` — чип 16, `--bg-raised` + граница `--line`, 11/400 `--text-secondary` (статус-строка,
пункты меню). `md` — чип 20, `--bg-panel` + граница `--line-strong`, 11/600 `--text-primary` (оверлей клавиш).
В статус-строке — только сочетания, которые реально работают на этом экране.

## Прикладные компоненты

| Компонент | Варианты / состояния |
|---|---|
| `EpisodeCard` | стадии: idea, script, generation, edit, ready, published; статус + прогресс стадии; затраты; дата слота; у published — CTR и просмотры за 48 часов |
| `SlotStrip` / `SlotCell` | слот занят · пуст («Назначить выпуск») · риск (warning + что не готово) · пропущен |
| `ShotCard` | статусы queued / generating / ready / failed; выбран; точки версий; бейдж анимации; причина отказа поверх кадра; действия по наведению |
| `ShotGrid` | группировка по разделам, прилипающие заголовки, мультивыделение, нижняя панель групповых действий |
| `ScriptSheet` | лист 760px, `--font-script` 13/20, номера кадров на левом поле, sluglines разделов, правое поле: миниатюра 120×68 или контурный плейсхолдер, значок движения, метка анимации, число SFX; всплывающая панель по выделению текста |
| `PlanTable` | 11 колонок, строки 28, правка в ячейке, мультивыделение, групповая правка |
| `JsonEditor` | подсветка, номера строк, строки с warning / fail подсвечены; панель валидации со ссылками на кадр |
| `Timeline` | дорожки Субтитры / Кадры / Голос / SFX / Музыка; маркеры разделов; плейхед `--accent`; клипы радиус 2, ink чёрный; бейдж перехода на стыке; пунктирная рамка warning при низкой уверенности тайминга; черновой режим (нет озвучки) — все клипы пунктиром; инструменты: выделение, лезвие, прилипание, масштаб |
| `Player` + `Transport` | таймкод, шаг по кадрам, петля, громкость, субтитры в превью, масштаб; блок сверки с голосом: «синхронно» / «разошлись на 1.6 с» + «Подогнать» |
| `ShotInspector` | секции: кадр, VO (подсветка текущего слова), промпт, длина (слайдер + замок «не подгонять под голос»), движение (8 вариантов + сила 3–25 % + кривая), кадрирование, переход; свёрнутые «Анимация» и «SFX» |
| `AnimationSection` | idle · running (штриховка, процент, отмена, работа не блокируется) · done (переключатель «Картинка / Видео»); бейдж рекомендации; лимит выпуска |
| `SfxSection` | таблица эффектов (смещение, длина, громкость, прослушать, удалить) + предложения из плана |
| `MultiSelectInspector` | общие поля показывают «разные значения»; любое изменение применяется ко всем; платные групповые действия с ценой и предупреждением о лимите |
| `RenderQueue` | задачи с этапами (кадры → склейка → звук → субтитры → финал), процент, текущий кадр, отмена, лог ffmpeg в панели, финальное состояние с превью и переходом к публикации |
| `ThumbnailCanvas` | варианты A/B/C, слои (фон, персонаж, текст, плашка), безопасная зона бейджа длительности, предпросмотр в трёх размерах ленты |
| `UploadPanel` | авторизация, способ (API / пакет для Studio), чеклист, возобновляемая загрузка, результат; предупреждение об аудите API |
| `SpendChart` / `OpsTable` | столбики по дням с цветом группы этапов, итоги по выпускам, средняя цена ролика, операции с выгрузкой CSV |
| `EmptyState` | иконка, заголовок, объяснение, primary (с ценой, если платно) + secondary, вспомогательная подпись |
| `ProcessCard` | этап, процент, шаги полосками, текущая единица, остаток, пауза, отмена |
| `ErrorCard` | kind: warning / failed; заголовок, что делать, техническая деталь монospace, обратный отсчёт повтора, две кнопки |
| `ConflictBar` | полоса warning + цена исправления + «Оставить старые»; таблица расхождений с выбором строк |
