# Studio — передача в Claude Code

Локальное desktop-приложение (браузер на ноутбуке): производственный пульт для
исторических YouTube-роликов из AI-кадров и закадрового голоса. Один пользователь,
два канала (Cursus, Otto's Timeline), цель — выпуск раз в два дня.

## Что в папке

| Файл | Содержимое |
|---|---|
| `tokens.css` | CSS variables: цвет, типографика, радиусы, плотность, размеры оболочки |
| `components.md` | Инвентарь компонентов: варианты, состояния, пропсы |
| `layout.md` | Размеры панелей, минимальные ширины, поведение при 1536 / 1920 / 2560 px |
| `stack.md` | Стек, структура репозитория, соглашения, порядок реализации |

Макеты-источники — `.dc.html` в корне проекта, экраны 1–10. Они кликабельны:
рельс этапов и главные действия ведут по сквозному сценарию.

## Сквозной сценарий (он же порядок реализации)

```
Выпуски ──「Новый выпуск」──▶ Идеи ──「Начать выпуск」──▶ Сценарий и план
   ▲                                                          │
   │                                            「Утвердить план」
   │                                                          ▼
Публикация ◀──「Перейти к публикации」── Экспорт ◀── Монтаж ◀── Генерация
```

Переходы в прототипе:

| Откуда | Действие | Куда |
|---|---|---|
| Выпуски | «Новый выпуск» → диалог → «Создать выпуск» | Сценарий и план |
| Идеи | «Начать выпуск» на карточке идеи | Сценарий и план |
| Сценарий | «Утвердить план» | Генерация |
| Генерация | рельс этапов → Монтаж | Монтаж |
| Монтаж | инспектор → «Анимация» / «SFX» | Инспектор (экран 6) |
| Монтаж | рельс этапов → Экспорт | Экспорт |
| Экспорт | «Перейти к публикации» (после рендера) | Публикация |
| Любой экран | «Studio» в верхней панели | Выпуски |

## Неизменяемые правила продукта

1. **Голос — ведущая дорожка.** Длительность кадра подстраивается под озвучку.
   Единица измерения времени в UI — реплика VO («под 00:00:14 VO»), рассинхрон
   помечается на клипе пунктирной рамкой warning, а не отдельным виджетом.
2. **Цена и время живут в кнопке и в статус-строке**, не в KPI-плитках.
   Платное действие всегда называет цену: «Сгенерировать 24 кадра (~$1.61)».
   Деньги — USD до цента, время — таймкоды `00:00:00`.
3. **Один акцент на экран.** Не больше одной залитой `--accent` кнопки.
4. **Цвет несёт информацию**: дорожки и статусы. Декоративного цвета нет.
   Статус различим формой, не только цветом.
5. **Каждый экран обязан иметь пустое, процессное и ошибочное состояние**
   (экран 10 — их каталог). Ошибка говорит, что случилось и что сделать, без извинений.
6. **Каналы изолированы**: свой токен Google, своя папка, свой канон стиля.
7. Тексты интерфейса — русский, sentence case. Одно действие — одно название:
   кнопка «Перерисовать» → тост «Перерисовано».
