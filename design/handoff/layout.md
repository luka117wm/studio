# Раскладка и размеры

Базовый вьюпорт **1536 × 864** (1920 × 1080 при масштабе 125 %). Корректно на
1920 × 1080 и 2560 × 1440. Мобильной версии нет, минимальное окно — 1280 × 720.

## Горизонтальные зоны

| Зона | Размер | Поведение |
|---|---|---|
| Рельс этапов | 56 фикс. | не меняется |
| Библиотека (Монтаж), Канон (Генерация) | 280 | тянется 240–360, свёртывается по `⌥1` |
| Метаданные (Публикация) | 380 | тянется 320–440 |
| Пресеты (Экспорт) | 320 | тянется 280–400 |
| Навигация настроек | 224 фикс. | не меняется |
| Рабочая зона | `1fr`, min 640 | забирает весь остаток |
| Инспектор / правая колонка | 320 | тянется 280–420, свёртывается по `⌥3` |
| Панель лога (Экспорт) | 420 | открывается кнопкой, поверх правой части |

## Вертикальные зоны

| Зона | Размер |
|---|---|
| Верхняя панель | 44 |
| Заголовок экрана | 52 (экраны со вкладками и счётчиками) |
| Шапка панели / таблицы | 28 / 24 |
| Полосы прогресса очередей (Генерация) | 72 |
| Таймлайн (Монтаж) | 260, ручка 4px, диапазон 160–460 |
| Нижняя панель выделения | 36–44 |
| Статус-строка | 24 |

Строки: список 28, таблица 28, расходы и свёрнутые секции 32, шапка таблицы 24.
Отступы только 4 / 8 / 12 / 16.

## Поведение по ширине

**1536 (база).** Монтаж: 280 + `1fr` + 320. Генерация: 280 + `1fr` + 320,
сетка кадров 5 в ряд. Сценарий: лист 760 по центру + 320. Экспорт: 320 + `1fr`,
лог 420 закрывает часть центра.

**1920.** Растёт только центр. Сетка кадров 6 в ряд, сетка обложек-предпросмотров
без переносов, таймлайн показывает то же окно времени при том же масштабе.
Боковые панели не растут.

**2560.** Центр получает вторую колонку:
- Сценарий — лист 760 + колонка раскадровки 320 справа от листа (миниатюры 16:9, 2 в ряд);
- Генерация — сетка кадров 8 в ряд;
- Монтаж — плеер до 1280 по ширине, таймлайн по умолчанию 320, дорожка кадров 96px высотой;
- Экспорт — лог открывается как третья колонка, центр не сужается;
- Расходы — график и итоги по выпускам в одну строку без переноса.
Инспектор остаётся 320 (тянется до 420), библиотека до 360: длина строки в панелях
не должна расти — плотность важнее заполнения.

**Ниже 1440.** Инспектор сжимается до 280, библиотека до 240. Ниже 1280 боковые
панели автоматически свёртываются в иконки, таймлайн уходит в 160.

## Скролл и прилипание

Прокручивается только содержимое панелей, не оболочка. Заголовки разделов в сетке
кадров и в библиотеке — `position: sticky; top: 0` с фоном `--bg-app` / `--bg-panel`.
Таймлайн скроллится горизонтально, подписи дорожек (72px) зафиксированы.

## Клавиатура

Всё доступно с клавиатуры, порядок табуляции идёт по зонам: верхняя панель → рельс
этапов → левая панель → рабочая зона → правая колонка → нижние панели.
Оверлей клавиш — по «?», закрытие по «?» и Esc: Space, J/K/L, ←/→ кадр,
Shift+←/→ раздел, S лезвие, D дублировать, Del, Ctrl+Z, Ctrl+Shift+Z,
R перерисовать, A оживить, M маркер, Ctrl+E экспорт, ⌘1…⌘6 этапы, ⌥1/⌥3 панели.
