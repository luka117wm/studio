# Roadmap

Единственный список того, что делаем. Одна строка — один микроэтап: статус · номер · название · task-файл · заметка.
Смысл буквы (подробнее — `CLAUDE.md`, «Как работаем»): **B** — что система умеет (контракт, хранилище, очередь,
провайдер, движок; проверяется тестами), **M** — что пользователь видит (оболочка, экран; на готовых B или моках).
Статусы: ☑ сделано · ◐ частично · ☐ не начат · ✎ task-файл ещё не написан (пишется при подходе к этапу).

Финиш этапа: ☑ здесь + запись в `STATUS.md` + коммит `Bx.y:` / `Mx.y:`.
