# Roadmap

Линейный порядок модулей. Правило: **детально расписан только текущий модуль**; следующий составляется после
закрытия текущего, по его итогам в `STATUS.md`; остальные — одной строкой, чтобы помнить направление.
Модуль = устав `docs/tasks/Mk.md` + этапы `docs/tasks/Mk.x.md`. Материал для будущих модулей — `docs/drafts/`.
Статусы: ☑ сделано · ◐ в работе · ☐ не начат.

Финиш этапа: ☑ здесь + запись в `STATUS.md` + коммит `Mk.x: …`. Финиш модуля: приёмка из устава + `git tag mk`.
