# Ключи провайдеров: где взять и куда положить

Когда нужны: **M2.6** — Anthropic, Gemini, ElevenLabs (проверка ключей `uv run pytest -m live`, запросы бесплатные).
Анимация (M8) новых ключей не требует: Veo работает на том же ключе Gemini; Kling и видео через API ElevenLabs —
по выбору, см. «Анимация кадров». YouTube OAuth — к публикации (M10). До M2.6 ничего заводить не надо: тесты идут
на фейковом провайдере, сеть замокана.

Цены, модели и тарифы ниже проверены **2026-09-23** по документации провайдеров. В коде их нет — только в
`config/providers.yaml` и `config/pricing.yaml` (принцип 5).

## Правила (принцип 9 `CLAUDE.md`)

- Секреты живут только в `backend/.env` и `data/channels/<channel>/oauth/`. Оба пути в `.gitignore`; фронт к
  провайдерам не ходит, ключи в браузер не попадают.
- Один ключ на сервис, а не на канал: каналы изолированы на уровне YouTube-аккаунтов и папок, а модели общие.
- Ключ утёк (попал в чат, лог, коммит) — отозвать и выпустить новый, не «переименовать».
- Подписка Claude из кода не используется — только API-ключ с оплатой по токенам.

## Установка

```bash
cp backend/.env.example backend/.env
chmod 600 backend/.env
$EDITOR backend/.env
писать значения ниже
uv run pytest -m live -v -rP  # проверка каждого ключа (бесплатно), без ключа — skip
```

`backend/.env`:

```
STUDIO_DATA_DIR=            # пусто = <репозиторий>/data
ANTHROPIC_API_KEY=sk-ant-…
GEMINI_API_KEY=AIza…
ELEVENLABS_API_KEY=…
KLING_ACCESS_KEY=           # M8, необязательно
KLING_SECRET_KEY=           # M8, необязательно
```

YouTube в `.env` не хранится — см. раздел ниже.

## Anthropic (сценарий, план, факт-чек — M4)

1. https://console.anthropic.com → войти → **API Keys** → *Create Key*, имя `studio-local`.
2. **Billing** → пополнить кредиты (оплата по токенам; для одного выпуска хватает единиц долларов).
3. Ключ показывается один раз — сразу в `backend/.env` как `ANTHROPIC_API_KEY`.
4. Модель и цены — в `config/providers.yaml` и `config/pricing.yaml`, не в коде.

## Google Gemini (кадры — M6, анимация Veo — M8)

1. https://aistudio.google.com → **Get API key** → *Create API key* (привязать к проекту Google Cloud; можно создать
   новый прямо оттуда).
2. Бесплатный уровень для генерации картинок не подходит — в Google Cloud включить биллинг на этом проекте
   (**Billing** → привязать платёжный аккаунт). Лимиты запросов в минуту смотреть там же, в **Quotas**.
3. Ключ → `GEMINI_API_KEY`.
4. `gemini-2.5-flash-image` не использовать — API закрывается осенью 2026 (`CLAUDE.md`); актуальная модель кадров
   задаётся в `config/providers.yaml`.
5. Модели кадров (в интерфейсе — «Nano Banana»), цена за картинку. Пакетный режим (Batch API) даёт скидку 50 %:


   | Название   | id                            | 1K                                                               | 2K     | 4K     |
   | ------------------ | ----------------------------- | ---------------------------------------------------------------- | ------ | ------ |
   | Nano Banana 2 Lite | `gemini-3.1-flash-lite-image` | $0,034                                                           | —     | —     |
   | Nano Banana 2      | `gemini-3.1-flash-image`      | $0,067                                                           | $0,101 | $0,151 |
   | Nano Banana Pro    | `gemini-3-pro-image`          | $0,134                                                           | $0,134 | $0,24  |
   | Nano Banana        | `gemini-2.5-flash-image`      | запрещена: закрывается 2 октября 2026 |        |        |

   В макетах экранов 4 и 9 модель названа «Nano Banana 2 Pro» — такой нет, это Nano Banana Pro. Цены в макетах —
   условные, настоящие берутся из `config/pricing.yaml`.
6. Veo (анимация) идёт на этом же ключе и биллинге, бесплатного уровня у Veo нет. Модели и условия — в разделе
   «Анимация кадров».

## ElevenLabs (голос — M7; видео — см. «Анимация кадров»)

1. https://elevenlabs.io → профиль (правый верхний угол) → **API Keys** → *Create API key*; права: Text to Speech,
   Voices, User (чтение подписки — нужно для квоты в шапке).
2. **Кредиты общие на всё:** голос, картинки и видео тратят один месячный пакет. Multilingual v2 — 1 кредит за
   символ; Flash/Turbo — 0,5–1 кредита за символ (дешевле, но проще голос).


   | Тариф | $/мес | Кредитов/мес | TTS по API | Картинки и видео в интерфейсе | Картинки и видео по API |
   | ---------- | -------- | ----------------------- | ------------ | ------------------------------------------------------ | --------------------------------------- |
   | Creator    | 22       | 121 000                 | да         | да                                                   | **нет** — `402 paid_plan_required`  |
   | Pro        | 99       | 600 000                 | да         | да                                                   | да                                    |
3. **Сколько нужно голосу.** Выпуск Cursus (20 мин) ≈ 18–25 тыс. символов, Otto (8 мин) ≈ 7–9 тыс. Выпуск раз в два
   дня — около 15 в месяц, это ≈ 200 тыс. символов на Multilingual v2 или v3 без перезаписей. Пакета Creator не
   хватает даже на один голос; недостачу закрывает Pay As You Go (ниже) или тариф Pro. Квота 600 000 в
   `tools/seed.py` — это Pro. Смена тарифа — в **Subscription**.
4. **Pay As You Go (оплата по факту).** Предоплаченное пополнение кредитов на любом самостоятельном тарифе, включая
   Free и Creator: минимум $5, кредиты живут 12 месяцев, тратятся после того, как кончился месячный пакет; есть
   автопополнение по порогу (по умолчанию: остаток ниже $10 → +$20). Старый usage-based billing (доплата в конце
   месяца) — только на старых подписках и Enterprise. Цены API по прайсу: v3 и Multilingual v2 — $0,10 за 1 000
   знаков, Flash — $0,05, звуковые эффекты — $0,12 за минуту. Как доллары пересчитываются в кредиты на конкретном
   тарифе, ElevenLabs показывает при пополнении. **Требование Pro для API картинок и видео пополнение, судя по
   документации, не снимает**: доступ к этому API зависит от тарифа, а не от баланса.
5. **Модели голоса.**


   | Модель    | id                       | Знаков за запрос | Для чего                                                                                                         |
   | --------------- | ------------------------ | ------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
   | Eleven v3       | `eleven_v3`              | 5 000                          | выразительная речь, аудиотеги, 70+ языков; выпуск Cursus — 4–5 запросов |
   | Multilingual v2 | `eleven_multilingual_v2` | 10 000                         | «самая стабильная на длинных текстах», 29 языков                                 |
   | Flash v2.5      | `eleven_flash_v2_5`      | 40 000                         | дёшево и быстро, голос проще; Turbo v2.5 устарел — вместо него Flash           |

   У всех трёх есть эндпоинт `with-timestamps` — посимвольные тайминги для выравнивания (M7).
6. Ключ → `ELEVENLABS_API_KEY`. Проверка `-m live` вызывает `/v1/user/subscription` и показывает остаток кредитов.

## Анимация кадров (M8): что можно подключить

Задача: оживить уже утверждённый кадр на 4–8 с (image-to-video: наш кадр — первый кадр ролика). Звук модели не нужен:
SFX и музыка у нас свои. Четыре пути:


| Путь                                                             | Что нужно                                          | Модели                                                                                                                                                      | Клип 4 с, 16:9                                                              | Автоматически                                                                           |
| -------------------------------------------------------------------- | ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **Veo через Gemini API** (по факту, за секунду) | тот же`GEMINI_API_KEY`, биллинг включён | `veo-3.1-lite-generate-preview`, `veo-3.1-fast-generate-preview`, `veo-3.1-generate-preview`                                                                      | Lite 720p —$0,20; Fast 720p — $0,40; Veo 3.1 — $1,60                          | да                                                                                                 |
| **ElevenLabs API**                                                   | тариф**Pro** и выше                              | `veo-3.1-generate-001`, `veo-3.1-fast-generate-001`; Seedance 2.x — только после одобрения заявки; `creatify-aurora` — липсинк | в кредитах; до запуска по API не узнать              | да                                                                                                 |
| **ElevenLabs вручную**                                        | Creator (уже есть)                                  | весь каталог интерфейса: Kling 2.5–3.0, Veo 3.1, Seedance, Wan, Runway, LTX…                                                               | в кредитах, интерфейс показывает до запуска | нет: скачать кадр → сгенерировать → импортировать клип |
| **Kling API**                                                        | отдельные пакеты на kling.ai/dev          | Kling 2.x–3.0, O3                                                                                                                                                | не проверено                                                          | да                                                                                                 |

**Veo через Gemini API** — самый короткий путь к автоматике. Ключ и биллинг те же, что для кадров. Цена — в долларах
за секунду, списывается только за успешную генерацию, так что «цена до клика» (принцип 6) считается точно.

- Длительность 4, 6 или 8 с; 1080p и 4K — только для 8 с; 16:9 или 9:16; 24 к/с; звук генерируется всегда.
- Цена за секунду: Lite — $0,05 (720p) / $0,08 (1080p); Fast — $0,10 / $0,12 / $0,30 (4K); Veo 3.1 — $0,40 / $0,40 /
  $0,60. Все три модели в статусе *preview*, id может смениться — только через `config/providers.yaml`.
- Асинхронно: long-running operation, опрос раз в ~10 с. Готовое видео хранится на сервере 2 дня — джоб скачивает
  его сразу в `media/`.
- **Люди в кадре:** для image-to-video доступен только `personGeneration: allow_adult`. Кадры с детьми (Cursus,
  `you@powder-monkey-11`) Veo, скорее всего, откажется анимировать — проверить на первом же кадре; запасной путь —
  ручной мост через ElevenLabs или Kling.
- В ролик вшит невидимый водяной знак SynthID; в публикации и так стоит `synthetic_media: true`.

**ElevenLabs API** (`POST /v1/flows/video` → `GET /v1/flows/video/{id}`):

- Только Pro и выше: на Creator и генерация, и загрузка ассетов (`/v1/assets`) отвечают `402 paid_plan_required`;
  пополнение Pay As You Go этого не меняет. Отдельного прайса «видео по факту» у ElevenLabs нет — только кредиты.
- **Kling через API недоступен** — только в интерфейсе. По API — Veo 3.1 и Veo 3.1 Fast, модели ByteDance (Seedance)
  по заявке, липсинк Creatify Aurora.
- Статусы `pending → generating → completed | failed`. Вебхуки требуют публичного адреса, поэтому у локального
  приложения — опрос; частый опрос получает 429.
- Первый кадр — `start_frame` (id ассета или base64 до 25 МБ). Вместе со `start_frame` нельзя передавать `images`
  (референсы). Для Veo — `enhance_prompt: false` (иначе модель переписывает промпт) и `generate_audio: false`.
- `content_url` — подписанная ссылка, живёт около часа: скачивать сразу; за новой ссылкой — повторный `GET`.
- Эндпоинта оценки цены нет: цены в кредитах переносятся в `config/pricing.yaml` вручную из интерфейса, с датой.
  По сторонним обзорам Veo 3.1 стоит порядка 8 000 кредитов за генерацию — не проверено, сверить в интерфейсе.
- Права ключа: при переходе на Pro добавить доступ к генерации картинок и видео и к ассетам (названия прав сверить
  в форме ключа).
- В каталоге есть Sora 2 и `gemini-2.5-flash-image` — не использовать (`CLAUDE.md`, «Чего не делать»).

**ElevenLabs вручную (Creator).** API видео нет, но интерфейс даёт весь каталог. В приложении это «мост», как для
LLM: этап анимации выдаёт кадр и промпт движения, пользователь генерирует клип в ElevenLabs, скачивает и
импортирует в кадр. Кредиты берутся из того же пакета, что голос, — см. раздел ElevenLabs.

**Kling API напрямую** (необязательно):

1. Портал разработчика — kling.ai/dev → создать приложение → **Access Key** и **Secret Key**.
2. По сторонним обзорам API оплачивается отдельными предоплаченными пакетами, веб-подписка Kling доступа к API не
   даёт. Сайт при проверке не открылся — цены и условия сверить на kling.ai/dev/pricing.
3. Ключи → `KLING_ACCESS_KEY`, `KLING_SECRET_KEY`. Пока пусто — путь помечается «провайдер не настроен».

Для любого пути лимит «анимация на выпуск» в бюджетах (M2.6) обязателен. Выбор пути — при составлении модуля M8.

## YouTube Data API v3 (публикация — M10)

Отдельно на каждый канал: у Cursus и Otto's Timeline свои Google-аккаунты (или бренд-аккаунты) и свои папки `oauth/`.

1. https://console.cloud.google.com → проект (можно тот же, что у Gemini) → **APIs & Services → Library** →
   *YouTube Data API v3* → **Enable**.
2. **OAuth consent screen**: тип *External*, статус *Testing*; в *Test users* добавить оба Google-аккаунта каналов.
   Публиковать приложение и проходить верификацию не нужно, пока пользователей двое.
3. **Credentials → Create credentials → OAuth client ID**, тип *Desktop app*, имя `studio-<channel>` → *Download JSON*.
4. Файл положить как `data/channels/cursus/oauth/client_secret.json` (и так же для `otto`). Никаких копий в `.env`.
5. Первая загрузка (M10) откроет браузер для входа под аккаунтом канала; токен сохранится в
   `data/channels/<channel>/oauth/token.json` и дальше обновляется сам.
6. Квота — 10 000 единиц в день на проект; одна загрузка видео стоит ~1 600, обновление метаданных ~50. Два канала
   в одном проекте укладываются с запасом.
7. **Аудит API**: пока проект не прошёл проверку Google, загруженные через него видео могут оставаться приватными
   до ручной публикации — экран публикации показывает это предупреждение. Проверку (YouTube API Services compliance
   audit) заказывать, когда пайплайн стабилен.

## Проверка и типовые ошибки


| Симптом                                                            | Причина                                                                                                                       | Что сделать                                                                                                                                                                     |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `401 invalid_api_key`                                                     | ключ скопирован не полностью или отозван                                                          | выпустить новый, обновить`.env`, перезапустить `./run.sh`                                                                                              |
| `403 billing` у Gemini                                                   | биллинг не включён на проекте ключа                                                                    | Google Cloud → Billing                                                                                                                                                                   |
| `429`                                                                     | лимит запросов в минуту; у ElevenLabs и Veo — ещё и слишком частый опрос статуса | очередь повторяет не раньше `Retry-After` (не дольше 60 с, `docs/jobs.md`); если повторяется — снизить `JOB_WORKERS` |
| Gemini `400 API key not valid` (`API_KEY_INVALID`)                        | неверный ключ: Gemini отвечает 400, а не 401; ключ скопирован не полностью, удалён или с лишними символами | выпустить новый в AI Studio, обновить `.env`; проверка покажет «ключ не принят (401)» |
| ElevenLabs `401 missing_permissions … user_read`                          | ключ верный, но без права User (чтение подписки)                                                  | в **API Keys** включить у ключа право User → Read (или выпустить ключ с ним); проверка покажет «нет доступа (403)» |
| ElevenLabs`402 paid_plan_required`                                        | генерация картинок и видео по API на тарифе ниже Pro                                            | Pro или путь «вручную» через интерфейс                                                                                                                      |
| Veo отказывает в генерации кадра с людьми | для image-to-video разрешены только взрослые (`allow_adult`)                                               | кадр с ребёнком анимировать через ElevenLabs или Kling вручную                                                                                     |
| ElevenLabs`quota_exceeded`                                                | символы месяца кончились                                                                                       | тариф или дождаться сброса; шапка показывает остаток                                                                                         |
| YouTube`insufficientPermissions`                                          | аккаунт не в*Test users* или не тот скоуп                                                                     | добавить аккаунт, удалить`token.json`, повторить вход                                                                                                  |

`uv run pytest -m live -v -rP` печатает по каждому провайдеру: ключ найден / нет, ответ, для ElevenLabs — остаток
символов. Для Anthropic и Gemini тест заодно проверяет, что модели из `config/providers.yaml` видны ключу.
