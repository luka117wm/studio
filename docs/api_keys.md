# Ключи провайдеров: где взять и куда положить

Когда нужны: **M2.6** — Anthropic, Gemini, ElevenLabs (проверка ключей, `uv run pytest -m live`, несколько центов).
Kling — к модулю анимации (M8), YouTube OAuth — к публикации (M10). До M2.6 ничего заводить не надо: тесты идут
на фейковом провайдере, сеть замокана.

## Правила (принцип 9 `CLAUDE.md`)

- Секреты живут только в `backend/.env` и `data/channels/<channel>/oauth/`. Оба пути в `.gitignore`; фронт к
  провайдерам не ходит, ключи в браузер не попадают.
- Один ключ на сервис, а не на канал: каналы изолированы на уровне YouTube-аккаунтов и папок, а модели общие.
- Ключ утёк (попал в чат, лог, коммит) — отозвать и выпустить новый, не «переименовать».
- Подписка Claude из кода не используется — только API-ключ с оплатой по токенам.

## Установка

```bash
cp backend/.env.example backend/.env
chmod 600 backend/.env
$EDITOR backend/.env          # вписать значения ниже
uv run pytest -m live -v      # после M2.6: проверка каждого ключа, без ключа — skip
```

`backend/.env`:

```
STUDIO_DATA_DIR=            # пусто = <репозиторий>/data
ANTHROPIC_API_KEY=sk-ant-…
GEMINI_API_KEY=AIza…
ELEVENLABS_API_KEY=…
KLING_ACCESS_KEY=           # M8, необязательно
KLING_SECRET_KEY=           # M8, необязательно
```

YouTube в `.env` не хранится — см. раздел ниже.

## Anthropic (сценарий, план, факт-чек — M4)

1. https://console.anthropic.com → войти → **API Keys** → *Create Key*, имя `studio-local`.
2. **Billing** → пополнить кредиты (оплата по токенам; для одного выпуска хватает единиц долларов).
3. Ключ показывается один раз — сразу в `backend/.env` как `ANTHROPIC_API_KEY`.
4. Модель и цены — в `config/providers.yaml` и `config/pricing.yaml`, не в коде.

## Google Gemini (кадры — M6)

1. https://aistudio.google.com → **Get API key** → *Create API key* (привязать к проекту Google Cloud; можно создать
   новый прямо оттуда).
2. Бесплатный уровень для генерации картинок не подходит — в Google Cloud включить биллинг на этом проекте
   (**Billing** → привязать платёжный аккаунт). Лимиты запросов в минуту смотреть там же, в **Quotas**.
3. Ключ → `GEMINI_API_KEY`.
4. `gemini-2.5-flash-image` не использовать — API закрывается осенью 2026 (`CLAUDE.md`); актуальная модель кадров
   задаётся в `config/providers.yaml`.

## ElevenLabs (голос — M7)

1. https://elevenlabs.io → профиль (правый верхний угол) → **API Keys** → *Create API key*; права: Text to Speech,
   Voices, User (чтение подписки — нужно для квоты в шапке).
2. Тариф выбирается по символам в месяц: один выпуск Cursus ≈ 20–25 тыс. символов, два выпуска в неделю — ~200 тыс.;
   квота 600 000 из фикстур соответствует уровню Creator/Pro. Смена тарифа — в **Subscription**.
3. Ключ → `ELEVENLABS_API_KEY`. Проверка `-m live` вызывает `/v1/user/subscription` и показывает остаток символов.

## Kling (анимация кадров — M8, необязательно)

1. Портал разработчика Kling (klingai.com → Developer / API) → создать приложение → **Access Key** и **Secret Key**.
2. Оплата — пакетами кредитов; анимация одного кадра на 4–5 с стоит десятки центов, поэтому лимит «анимация на выпуск»
   в бюджетах (M2.6) обязателен.
3. Ключи → `KLING_ACCESS_KEY`, `KLING_SECRET_KEY`. Пока пусто — этап анимации помечается «провайдер не настроен».

## YouTube Data API v3 (публикация — M10)

Отдельно на каждый канал: у Cursus и Otto's Timeline свои Google-аккаунты (или бренд-аккаунты) и свои папки `oauth/`.

1. https://console.cloud.google.com → проект (можно тот же, что у Gemini) → **APIs & Services → Library** →
   *YouTube Data API v3* → **Enable**.
2. **OAuth consent screen**: тип *External*, статус *Testing*; в *Test users* добавить оба Google-аккаунта каналов.
   Публиковать приложение и проходить верификацию не нужно, пока пользователей двое.
3. **Credentials → Create credentials → OAuth client ID**, тип *Desktop app*, имя `studio-<channel>` → *Download JSON*.
4. Файл положить как `data/channels/cursus/oauth/client_secret.json` (и так же для `otto`). Никаких копий в `.env`.
5. Первая загрузка (M10) откроет браузер для входа под аккаунтом канала; токен сохранится в
   `data/channels/<channel>/oauth/token.json` и дальше обновляется сам.
6. Квота — 10 000 единиц в день на проект; одна загрузка видео стоит ~1 600, обновление метаданных ~50. Два канала
   в одном проекте укладываются с запасом.
7. **Аудит API**: пока проект не прошёл проверку Google, загруженные через него видео могут оставаться приватными
   до ручной публикации — экран публикации показывает это предупреждение. Проверку (YouTube API Services compliance
   audit) заказывать, когда пайплайн стабилен.

## Проверка и типовые ошибки

| Симптом | Причина | Что сделать |
|---|---|---|
| `401 invalid_api_key` | ключ скопирован не полностью или отозван | выпустить новый, обновить `.env`, перезапустить `./run.sh` |
| `403 billing` у Gemini | биллинг не включён на проекте ключа | Google Cloud → Billing |
| `429` | лимит запросов в минуту | очередь M2.5 повторяет сама с задержкой; снизить параллельность в настройках |
| ElevenLabs `quota_exceeded` | символы месяца кончились | тариф или дождаться сброса; шапка показывает остаток |
| YouTube `insufficientPermissions` | аккаунт не в *Test users* или не тот скоуп | добавить аккаунт, удалить `token.json`, повторить вход |

`uv run pytest -m live -v` печатает по каждому провайдеру: ключ найден / нет, ответ, для ElevenLabs — остаток квоты.
