# Исследование: идеи и референс

Контракт того, откуда берутся темы выпусков (устав M4, решения 9 и 10). Раздел «Идеи» — M4.8, «Референс» — M4.10.
Радара трендов YouTube нет (нужен ключ YouTube Data API): идеи заводятся руками и приходят из чата через мост
(`docs/bridge.md`). Поэтому у идеи нет «доказательств», «насыщенности» и прочих полей, для которых нет данных.

## Идеи

Код: таблица `ideas` (миграция `007_ideas.sql`), модели `backend/app/models/idea.py`, роутер
`backend/app/api/ideas.py`, разбор ответа чата — `backend/app/pipeline/research/ideas.py`, шаблон промпта —
`backend/app/prompts/ideas.md`. Типы фронта — `@/types/idea`.

### Поля идеи (`Idea`)

| Поле | Тип | Описание |
|---|---|---|
| `id` | `i0001`, `i0002`, … | глобальный номер; выдаётся внутри `BEGIN IMMEDIATE` (L-021) |
| `channel` | `cursus \| otto` | канал; не меняется |
| `title` | str, 1…200 после `strip` | рабочее название; станет названием выпуска |
| `angle` | str | чем подача отличается от очевидной |
| `hook_promise` | str | обещание первых 30 секунд |
| `summary` | str | о чём выпуск, 2–3 предложения |
| `score` | int 0–100 \| `null` | **мнение чата**, а не данные: просмотров и поисковых чисел у чата нет. Так сказано и в промпте |
| `score_reason` | str \| `null` | почему такая оценка, одно предложение |
| `source` | `manual \| bridge` | заведена руками или пришла из чата; не меняется |
| `status` | `proposed \| backlog \| used \| dropped` | ниже |
| `episode_id` | str \| `null` | выпуск, созданный из идеи (`used`) |
| `created_at`, `updated_at` | ISO 8601 UTC | `updated_at` растёт при каждой правке |

Тексты ошибок — одна русская фраза на поле (L-022): «Название не может быть пустым — введите текст.», «Название
длиннее 200 знаков — сократите его.», «Оценка — целое число от 0 до 100 или null.» Оценка `85.0` принимается как 85.

### Статусы

| Статус | Что значит | Куда можно (PATCH) |
|---|---|---|
| `proposed` | предложил чат, в бэклог ещё не взята | `backlog`, `dropped` |
| `backlog` | в бэклоге; заведённая руками идея начинается здесь | `dropped` |
| `dropped` | отброшена; физически идеи не удаляются | `backlog` |
| `used` | взята в выпуск — конечный | никуда |

`used` ставит только создание выпуска из идеи. Неверный переход — **409** с текстом: «Идею со статусом «в бэклоге»
нельзя перевести в «предложена»: можно «отброшена».» Тот же статус — не переход: ничего не меняется.

### Семена ниши

`profile.json → seeds` канала: короткие строки-направления для промпта идей («pirate ships», «Roman legions»).
Живут в профиле, не в коде и не в конфиге.

- `PATCH /api/channels/{id} {seeds}` — только семена; профиль пишется атомарно (temp → rename, L-003).
- Строки после `strip`, пустые выбрасываются; не больше 20, каждая до 80 знаков, без повторов без учёта регистра.
  Нарушение — 422 одной фразой: «Семя «pirates» повторяется — оставьте одно.»
- Пустой список допустим: промпт тогда опирается на формат канала. Пустой список в `profile.json` и в ответе API
  не выгружается — в TS поле `seeds?:` (L-033), обязательным его сделает экран идей.

### Промпт идей

`POST /api/ideas/prompt {channel, count}` (`count` 1…20, по умолчанию 6) → `{text, prompt_id, version, run_id,
count}` и строка журнала моста `task: ideas`, `prompted`. Контекст шаблона `ideas`:

| Ключ | Что |
|---|---|
| `channel_name`, `format` | имя и формат канала; описание обоих форматов — в тексте шаблона |
| `preset_json` | минуты `{min, target, max}`, разделы, слов в минуту — из `config/formats.yaml` |
| `seeds_json` | семена ниши; `[]` — семян нет |
| `avoid_json` | «не повторять»: названия идей бэклога, затем выпусков канала (без «Новый выпуск»), без повторов |
| `count` | сколько идей |

Предложенные (`proposed`) и отброшенные идеи в «не повторять» не входят: первые ещё не решены, вторые можно
предложить заново. Эталон текста — `tests/fixtures/prompts/ideas_cursus.txt`; правка шаблона поднимает `version`.

### Приём ответа

`POST /api/ideas/answer {channel, text}` → `{run_id, created: [Idea], skipped: [{index, title, reason}]}`.

1. `extract_json` (`docs/bridge.md`, «Разбор ответа»); дальше — `{"ideas": [...]}`. Списка нет или он пуст — 422
   `BridgeError` «В ответе нет списка идей: ожидался {"ideas": [...]}.»
2. Каждая идея проверяется отдельно (`IdeaProposal`: `title`, `angle`, `hook_promise`, `summary` обязательны,
   `score` и `score_reason` — нет; лишние ключи чата не мешают). Ошибка одной идеи не роняет остальные: она
   пропускается с причиной («нет поля «angle»»).
3. **Дубль названия** (без регистра и лишних пробелов) — пропуск с пометкой: с идеями канала, кроме `dropped`
   («уже в бэклоге», «уже предложена», «уже взята в выпуск»), с выпусками канала («уже есть выпуск с таким
   названием») и с идеей выше в том же ответе. Повторная вставка того же ответа ничего не удваивает.
4. Принятые сохраняются `proposed`, `source: bridge`, в порядке ответа.
5. Журнал: открытый обмен `ideas` канала закрывается этим ответом, иначе пишется новая строка (как у плана).
   Принята хотя бы одна идея — `applied`, пропуски — в `errors` обмена («идея 3: …», путь `ideas[2]`). Не принята
   ни одна — 422 `BridgeError` «Ни одна идея не принята: 2 пропущены.» с ошибками по идеям, обмен `failed`, в
   `ideas` ничего не пишется.

### API

| Запрос | Ответ |
|---|---|
| `GET /api/ideas?channel=&status=` | `[Idea]`, новые первыми; фильтры необязательны |
| `POST /api/ideas` `IdeaCreate {channel, title, angle, hook_promise, summary, score, score_reason}` | 201 `Idea`: `manual`, сразу `backlog`; 404 — канала нет |
| `PATCH /api/ideas/{id}` `IdeaPatch` | `Idea`; тексты и оценка (`score: null` — сброс), статус по таблице; 409 — переход; 422 — `channel`, `source`, `episode_id`, `id`, даты; 404 — идеи нет |
| `POST /api/ideas/prompt`, `POST /api/ideas/answer` | выше |
| `PATCH /api/channels/{id}` `{seeds}` | `ChannelProfile` |

### Выпуск из идеи

`POST /api/episodes {channel, origin: "backlog", idea_id}` (`docs/episodes.md`), одной транзакцией с созданием:

- идея должна быть этого канала (иначе 422) и в бэклоге (иначе 409: «… взята в выпуск c01 — выпуск создаётся только
  из идеи в бэклоге.»); нет идеи — 404; `idea_id` без `origin: backlog` — 422;
- название выпуска — название идеи, если `title` не прислан явно;
- заявка (`project.json → brief`): `idea` ← название, `angle`, `hook_promise`, `notes` ← `summary`, `idea_id`;
- стадия `idea`; идея → `used`, `episode_id` — выпуск.

Отказ ничего не оставляет: ни каталога, ни строки выпуска, статус идеи прежний.
