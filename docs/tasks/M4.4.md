# M4.4 — Экран «Сценарий и план»: заявка, панель моста, режимы

**Модуль:** M4 — Идеи, сценарий и план через мост · **Оценка:** 4 ч · **Модель:** Sonnet · **План до кода:** да

## Цель
На экране 3 заполняется заявка. Промпт копируется по частям, ответы чата вставляются, ошибки видны по-русски, а
принятый план появляется на экране. В заголовке — режимы «Сценарий / План кадров / JSON» по ⌘⇧1…⌘⇧3 и счётчики. У
источника плана сегмент «Claude API» выключен с подсказкой.

## Что сделать
1. **Режимы.**
   - SegmentedControl в заголовке; ⌘⇧1…⌘⇧3 регистрируются в группе «Сценарий» с подсказками статус-строки
     («⌘⇧1 сценарий» …).
   - Режим — в адресе (`?mode=plan`), чтобы перезагрузка и ссылка его сохраняли.
2. **Счётчики** из действующего плана: слова VO, кадры, хронометраж по тексту (слова ÷ темп пресета), темп.
   Плана нет — «—».
3. **Пустое состояние.**
   - Плана нет: в центре заявка и пояснение «План приходит из чата частями по 26 кадров».
   - Без заявки кнопка копирования выключена с подписью «Заполните идею».
4. **Копирование.**
   - Клик → `POST …/plan/prompt?part=k` → `navigator.clipboard.writeText`.
   - Тост «Промпт части 2 из 4 скопирован».
   - Буфер недоступен — диалог с текстом промпта и подсказкой «Выделите и скопируйте вручную».
   - Номер части — следующей недостающей; другую часть выбрать нельзя — порядок держит бэкенд.
5. **Вставка.**
   - «Применить вставку» выключена при пустом поле.
   - Ответ → `POST …/plan/answer`. Успех: тост «Часть 2 из 4 принята, 26 кадров» либо, на последней, «План v003:
     +104 кадра», поле очищается.
   - Ошибка: карточка в стиле ErrorCard — текст, подсказка, список ошибок с id кадра. Поле не очищается.
6. **Полоски частей:** принята — `ready`, ждёт — `queued`, последняя с ошибкой — `failed`. Подпись: «Часть 1
   вставлена, 26 кадров. Ждёт часть 2.»
7. **Последний прогон.** Строка «Последний обмен: сегодня 11:58, часть 2» из `bridge_runs`, без суммы (мост — $0).
8. **Чекбокс артборда «Добавить к текущему плану» не делается:** часть определяет `meta.part` ответа. Строка в
   `docs/visual_review.md`: «осознанно».

## Критерии приёмки
- [ ] без заявки копирование выключено; с заявкой — запрос промпта, буфер (мок `navigator.clipboard`), тост
- [ ] вставка ответа: успех — полоска части `ready` и подпись; ошибка — текст и список с id кадра, поле не
      очищено (моки API)
- [ ] ⌘⇧1…⌘⇧3 переключают режим и видны в статус-строке; ⌘1…⌘6 по-прежнему этапы
- [ ] дубль сочетания в `register()` даёт предупреждение (тест)
- [ ] «Claude API» выключен, Tooltip с причиной
- [ ] `pnpm -C frontend test --run && lint && build`; hex в новых файлах нет
- [ ] вживую (рецепт из памяти: временный `STUDIO_DATA_DIR`, `pnpm dev`, браузер — скрипт `@playwright/test`):
      заявка → промпт части 1 в буфере → ответ настоящего чата → часть принята, полоска зелёная
