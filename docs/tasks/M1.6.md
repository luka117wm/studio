# M1.6 — Визуальная приёмка

**Модуль:** M1 — Оболочка · **Оценка:** 2 ч · **Модель:** Sonnet · **План до кода:** нет

## Цель
Скриншоты приложения сверены с артбордами, расхождения либо исправлены, либо записаны с обоснованием; появился эталонный набор снимков для регрессии.

## Читать
- `docs/tasks/M1.5.md` и список расхождений с предыдущей сессии
- `design/handoff/layout.md`
- `frontend/e2e/` (создаётся здесь)

## Создать / изменить
- `frontend/e2e/visual.spec.ts` — снимки всех экранов на трёх ширинах
- `frontend/e2e/__screenshots__/` — эталоны
- `frontend/playwright.config.ts`
- `docs/visual_review.md` — таблица расхождений: экран, что не совпало, решение

## Не трогать
- `design/**`

## Что сделать
1. Playwright: снимки двенадцати экранов на 1536, 1920 и 2560, плюс отдельные снимки открытого диалога, меню и тоста.
2. Через Playwright MCP открыть соответствующий артборд `design/Studio - N *.dc.html` и снять его в той же ширине. Сверять попарно: раскладка зон, ширины панелей, плотность, размеры шрифтов, отступы. Цвета сверять по переменным, а не по глазу.
3. Каждое расхождение — строка в `docs/visual_review.md` с одним из трёх решений: исправлено в коде, отличается осознанно (с причиной), требует правки макета.
4. Исправлять только то, что относится к оболочке и киту. Расхождения в содержимом экранов — не дефект: содержимого пока нет.
5. Порог сравнения с эталоном задать так, чтобы антиалиасинг шрифтов не давал ложных срабатываний, но сдвиг на два пикселя ловился.
6. Эталоны закоммитить. Дальше любой модуль, ломающий оболочку, будет падать на этом тесте.

## Критерии приёмки
- [ ] `pnpm -C frontend e2e` зелёный, эталоны созданы
- [ ] `docs/visual_review.md` содержит строку на каждое расхождение
- [ ] незакрытых расхождений в раскладке и ките не осталось
- [ ] повторный прогон стабилен (три раза подряд без флаки)

## Команды проверки
```bash
pnpm -C frontend e2e
pnpm -C frontend e2e && pnpm -C frontend e2e   # проверка на флаки
```

## Чего не делать
- не поднимать порог сравнения, чтобы тест позеленел
- не исправлять содержимое экранов
