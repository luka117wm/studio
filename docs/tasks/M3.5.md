# M3.5 — Экран «Выпуски»: доска и карточки

**Модуль:** M3 — Выпуски и календарь слотов · **Оценка:** 4 ч · **Модель:** Sonnet · **План до кода:** да

## Цель
Экран 1 показывает выпуски из `/api/episodes` на доске из шести колонок по стадиям: карточка с названием, каналом,
длительностью, статусом, строкой «что сейчас», прогрессом, расходом и слотом. Работают поиск и фильтр каналов.
Клик открывает выпуск на его этапе.

## Что сделать
1. **Колонки.** Идея (`idea`), Сценарий (`script`), Генерация (`generate`), Монтаж (`edit`), Готов к публикации
   (`export` со статусом `ready` или `publish` без `published`), Опубликован (`published`). Стадия `export` в работе
   остаётся в «Монтаже».
   Правило — одна функция с тестом на все пары стадия × статус. Совпасть должно с документом M3.1.
2. **Метки колонок и глифы** — токены по смыслу:
   - идея — `queued`;
   - сценарий — `track-subtitles`;
   - генерация — `track-shots`;
   - монтаж — `track-voice`;
   - готов — `accent`;
   - опубликован — в артборде `#6F86B5`, **в `tokens.css` такого цвета нет**: взять `ready` (сплошная точка) и
     записать строку в `docs/visual_review.md` и в список правок handoff перед M4 (новый токен `status.published`).
3. **Строка «что сейчас»** — по артборду:
   - генерация: «Кадры 78 из 104, ~9 мин»;
   - ошибки: «12 кадров не удались»;
   - сценарий: «Сценарий 2 140 / ~3 000 слов»;
   - идея без данных: «Идея».

   Цвет: fail-text / warning / accent / muted. Оценка оставшегося времени — только при идущем джобе, по его
   прогрессу. Иначе без неё, не выдумывать.
4. **Прогресс карточки** — доля стадии из сводки: кадры `done / total` на генерации, 1 у готовых, 0 у идеи без
   данных. Заливка: штриховка при `generating`, fail, warning, queued, ready — как `barFillStyle` артборда, только
   классами токенов.
5. **Расход** — `formatUsd(summary.spent_usd_micro)`. **Слот** — `formatSlotDate`: «сегодня» — accent, нет слота —
   «слот не назначен».
6. **Длительность:** `19:48` по голосу, «~18:00» по оценке или цели плана, «—» без данных.
7. **Поиск** — по названию и короткому имени без учёта регистра. Фильтр канала — `uiStore.channel`; счётчик
   считает видимые из всех.
8. **Клик и Enter по карточке** открывают выпуск: `uiStore.openEpisode(episode)` (канал переключается, M3.3) и
   переход на `paths.stage(id, stage)`. Карточка — ссылка с доступным именем «<название>, <колонка>».
9. **Состояния экрана:**
   - загрузка — скелетоны карточек в колонках;
   - нет выпусков — `EmptyState` «Выпусков пока нет» с primary «Новый выпуск»;
   - поиск без результатов — «Ничего не найдено по «…»» с «Сбросить поиск»;
   - ошибка — текст бэкенда в зоне доски.
10. Длинные колонки прокручиваются внутри себя, заголовок колонки прилипает (`layout.md`, «Скролл»).
