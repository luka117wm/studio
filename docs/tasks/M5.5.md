**Модуль:** M5 — Канон · **Оценка:** 4 ч · **Модель:** Opus · **План до кода:** да

## Цель
Итоговый запрос картинки любого кадра — промпт, negative, референсы и seed — собирает код из канона и действия кадра.
Он детерминирован, и его видно до траты денег: у каждой секции подписан источник.

## Что сделать
1. **Секции в фиксированном порядке:** `style` → `period` → `appearance` (по облику кадра, в порядке
   `shot.image.appearances`) → `action` (`shot.image.prompt` действующего плана, с правкой человека) → `shot_size`.
   Разделитель и формат каждой секции — в `docs/prompt_assembly.md`. Версии канона — из `canon_ref` выпуска (M5.2).
2. **Negative** — `negative_global ∪ forbidden ∪ negative_local` всех обликов кадра. Без повторов (без учёта
   регистра), порядок стабильный: по слою, внутри — как в каноне.
3. **Референсы:**
   - ракурсы выбранного листа каждого облика по крупности кадра (`config/canon.yaml`), затем до двух кадров стиля;
   - больше лимита модели — первыми уходят кадры стиля, затем ракурсы сверх фаса у последнего облика; фас — никогда;
   - не хватает места даже для фасов — ошибка с id кадра, а не тихая обрезка;
   - референсы — только файлы листов и кадров стиля (принцип 13).
4. **Seed** — детерминированный от хэша (`episode_id`, `shot.id`, версии канона, действие).
5. **Хэш входов** — тот же `input_hash` шлюза по маршруту `images`: одинаковые входы — одинаковый хэш. Это ключ кэша
   кадра в M6. Смена версии стиля, эпохи или облика меняет хэш.
6. **Ошибки по-русски с id кадра:**
   - канон не резолвится («кадр s047: облик you@captain-35 не опубликован»);
   - нет листа или лист устарел;
   - стилевой токен в действии (стоп-лист M2.2, тот же `load_stoplist`).
7. **Предпросмотр** — `GET …/shots/{shot_id}/prompt`:
   - секции `{source: "style/v003" | "periods/…" | "characters/…#…" | "shot", label, text}`, итоговый текст и
     negative;
   - референсы с подписью («you@powder-monkey-11 — фас»), seed, модель и цена кадра по `gateway.estimate`;
   - проблемы — списком, а не 500.
8. `docs/prompt_assembly.md` — три разобранных примера из фикстуры: один персонаж; два персонажа; кадр без
   персонажа (`detail`).
9. **Тесты:**
   - 20 кадров дважды — побайтово одинаковые промпты и хэши;
   - смена версии стиля и облика меняет хэш;
   - порядок секций и negative без повторов;
   - лимит референсов (уходят кадры стиля, фас остаётся);
   - стоп-лист с id кадра;
   - предпросмотр с источниками.
