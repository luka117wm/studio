# M4.6 — Смета плана и «Утвердить план»

**Модуль:** M4 — Идеи, сценарий и план через мост · **Оценка:** 3 ч · **Модель:** Opus · **План до кода:** да

## Цель
Бэкенд считает смету действующего плана через gateway: кадры, голос, анимация и строка плана «мост через чат, $0» —
с остатком месячного бюджета. «Утвердить план» проверяет план, фиксирует утверждённую версию и переводит выпуск в
стадию «Генерация». Смета пресета в диалоге M3 при мосте не включает строку сценария.

## Что сделать
1. **Строки сметы** — запросами того же объёма, что выпуск (как `estimate_episode` в M3.2):
   - кадры — число кадров плана без `removed` × маршрут `images`;
   - голос — символы всех VO действующего плана, маршрут `voice`;
   - анимация — кадры с `animate.recommended` × `animate.seconds`, маршрут `animate`;
   - план — при `bridge` строка «Мост через чат» с $0; при `api` — оценка маршрута `script` (на будущее, в M4 не
     используется).

   У каждой строки — подпись для экрана («104 × $0.067», «23 400 знаков», «6 клипов × $0.32»).
2. **Бюджет.** Итог; потрачено за месяц, лимит и остаток после выпуска («Останется $75.20 из месячных $150»); лимит
   выпуска из профиля канала. Превышение — предупреждение в ответе, не отказ (решение 8). `stale_pricing` — как в
   M3.2.
3. **Утверждение** — что проверяется:
   - план есть и все части собраны;
   - у каждого кадра (не `removed`) непустые VO и промпт — после правок;
   - для выпуска из референса — проверка сходства (точку расширения оставляет этот этап, саму проверку добавит
     M4.10).

   Отказ — 409 `{message, problems[{shot_id, message}]}`: «2 кадра без VO: s063, s071».
4. **Успех.**
   - `approved_version` = текущая версия, `approved_at`, стадия `generate`, ответ `EpisodeListItem`.
   - Повтор для той же версии — 200 без изменений.
5. **Новая версия после утверждения:**
   - стадия `generate` → `script`;
   - `approved_version` остаётся как история;
   - действующий план (`GET …/plan`) показывает, что утверждённая версия старше текущей.

   Поздние стадии (после начала генерации) — решение M6. Строка в `docs/episodes.md`.
6. **Смета пресета** в `GET /api/formats`: при мосте строка сценария — $0 с пометкой. Сверка с артбордом
   («~$3.80» против живых «~$8.99») — числа в `STATUS.md`, цены не правятся (хвост M3.2).

## Критерии приёмки
- [ ] смета фикстурного плана совпадает с суммой, посчитанной в тесте прямо из `pricing.yaml`; строка плана при
      мосте — $0
- [ ] остаток месяца из журнала и профиля; превышение — предупреждение
- [ ] утверждение: кадр без VO после правки → 409 со списком; полный план → стадия `generate`,
      `approved_version` записана; повтор — без изменений
- [ ] импорт новой версии при `generate` → `script`
- [ ] `GET /api/formats` при мосте — строка сценария $0
- [ ] `uv run pytest && uv run ruff check . && uv run mypy backend tests`; `typegen:check`
