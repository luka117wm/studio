# M6.3 — Пачка кадров: смета и бюджет суммой, пауза, отмена, параллельность

**Модуль:** M6 — Генерация · **Оценка:** 5 ч · **Модель:** Opus · **План до кода:** да

## Цель
Выпуск генерируется целиком одной пачкой: сумма — до постановки, не влезает в бюджет — ни одного джоба; пачку можно
поставить на паузу, продолжить и отменить, упавшие кадры — повторить, а статус выпуска показывает, идёт ли работа и
есть ли что проверить.

## Что сделать
1. **Выбор кадров** (решение 4): без `shots` — кадры без выбранной картинки и `stale`; с `shots` — эти. `removed` и
   кадры с `problems` сборщика — не ставятся; ответ перечисляет пропущенные с причиной.
2. **Смета** — `GET …/generate/estimate`: число кадров × цена модели, по кадрам; кэш не вычитается (оценка сверху,
   как у листов). Она же — сумма в кнопке экрана 4.
3. **Бюджет суммой.** Сначала проверяется вся сумма против выпуска и месяца (`Gateway.check_budget`), потом одной
   транзакцией (`BEGIN IMMEDIATE`, L-021) создаются пачка и джобы. Не влезает — 409 `BudgetRefusal` с суммой пачки,
   строка `refused` в журнале, ни одного джоба (хвост M4, раздел 38). Тест на гонку двух пачек.
4. **Один кадр — одна незаконченная пачка:** кадр уже в `queued`/`running` джобе другой пачки — 409 с id пачки.
5. **Параллельность.** Вид `shot_image` берёт не больше `images_parallel` одновременных, общий пул (`job_workers`) не
   растёт и делится с другими видами. Тест: 10 джобов, лимит 3 — одновременно не больше трёх.
6. **Пауза / продолжить / отмена.** Пауза — флаг пачки: пул не берёт её `queued`, идущие доделывают; переживает
   перезапуск бэкенда. Отмена — `cancel` всех незаконченных джобов пачки, начатые доделываются (как в артборде:
   «Очередь отменена, начатые кадры дорисуются»), освобождается оценка в бюджете.
7. **«Повторить упавшие»** — новая пачка из кадров `failed` последней пачки, тот же вариант и модель; кадры с
   отказом фильтра без правки повторяются только явно (их список — в ответе с предупреждением).
8. **Сводка пачки** — `GET /api/batches/{id}`: всего, готово, рисуется, в очереди, упало, потрачено, оценка, пауза,
   оценка времени (по средней длительности готовых). Событие `batch.updated` — при каждом переходе джоба пачки.
9. **Статус выпуска** (решение 5): пачка идёт — `generating`; закончилась — `ready` (у всех кадров плана выбрана
   картинка, нет `failed` и пометок проверки) или `warning`. Стадия остаётся `generate`.

## Критерии приёмки
- [ ] `uv run pytest tests/test_batches.py tests/test_jobs.py -v` зелёные
- [ ] пачка сверх лимита выпуска — 409 с суммой, `cost_ledger` — строка `refused`, джобов 0
- [ ] пауза: после паузы новые джобы не стартуют, начатые доходят до `done`; продолжить — остальные идут
- [ ] сбой одного кадра (фейковый отказ фильтра) — `failed`, остальные `done`, статус выпуска `warning`
- [ ] вручную на временном `STUDIO_DATA_DIR` и временном `CONFIG_DIR` (копия `config/`, маршрут `images` —
      `provider: fake`, как в тестах; $0): пачка из 20 кадров → пауза → перезапуск uvicorn → пауза на месте →
      продолжить → 20 версий, статус выпуска `ready`
