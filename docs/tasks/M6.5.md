# M6.5 — Сходство лица: YuNet + SFace, фас облика, `consistency_low`

**Модуль:** M6 — Генерация · **Оценка:** 4 ч · **Модель:** Opus · **План до кода:** да

## Цель
У каждой новой версии кадра с персонажем посчитано сходство лица с выбранным фасом его облика, и кадры, где
персонаж перестал быть собой, помечены `consistency_low` — локально, бесплатно, без блокировки.

## Что сделать
1. **Веса.** YuNet (`face_detection_yunet_2023mar.onnx`, MIT) и SFace (`face_recognition_sface_2021dec.onnx`,
   Apache 2.0) из opencv_zoo; лицензия и источник — в `config/checks.yaml` и `docs/generation.md`. Без весов проверка
   — `skipped` с предупреждением в журнале и подсказкой «запустите fetch_models», генерация не падает. В git веса не
   кладутся.
2. **Эталон** — выбранный фас листа облика той версии, к которой прибит выпуск (тот же, что в референсах кадра).
   Нет лица на фасе — `skipped` для облика с причиной.
3. **Кадр.** Все лица кадра (YuNet, минимальный размер из конфига), выравнивание и эмбеддинг (SFace), для каждого
   облика кадра — лучшее сходство среди лиц. Ниже порога — `low`; лиц нет — `no_face` («не проверено», не
   подозрение). Кадр без обликов — проверки нет.
4. **Порог** — мягкий по умолчанию: задача — поднять подозрительные наверх, а не блокировать. Значение подбирается на
   фикстурах и записывается с обоснованием в `config/checks.yaml`.
5. **Фикстуры** — свои картинки, не чужие фото: фас облика A, другой ракурс A, фас облика B и кадр без лица.
   Генерируются нашим же Gemini Pro один раз (~$0.40, согласие пользователя), коммитятся в `tests/fixtures/faces/`.
6. **Тесты** — логика сходства и статусов на фейковом эмбеддере (без весов); проверка на настоящих весах —
   `pytest -m models` вручную после `fetch_models`: A-ракурс ближе к фасу A, чем B; кадр без лица — `no_face`.
7. **Ресурс** — CPU. Проверка идёт внутри `shot_image` после картинки и не задерживает следующую: тяжёлое (загрузка
   весов) — один раз на процесс.
8. **`POST …/shots/{id}/check`** — джоб `shot_check` для выбранной версии; бесплатный.

## Критерии приёмки
- [ ] `uv run pytest tests/test_face_check.py -v` зелёные (без весов)
- [ ] `uv run python -m app.tools.fetch_models` скачивает веса и проверяет sha256; повтор — ничего не качает
- [ ] `uv run pytest -m models -v` (вручную, с весами): сходство A–A выше порога, A–B ниже, кадр без лица — `no_face`
- [ ] без весов `shot_image` завершается, у версии `checks.face.status = skipped`
- [ ] вручную на временных данных: версия кадра с фикстурой B вместо картинки облика A — `low` в метаданных версии
