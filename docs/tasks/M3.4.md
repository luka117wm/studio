## Что сделать
1. `ChannelSwitcher` и фильтр «Все / Cursus / Otto» экрана 1 (M3.5) — одно состояние `uiStore.channel`. Смена
   канала при открытом выпуске другого канала закрывает выпуск и уводит на «Выпуски» — правило M1.3 сохраняется.
2. Клавиатура: переключатель доступен с Tab, меню — стрелками, Esc закрывает. Новых глобальных сочетаний нет (в
   handoff их у канала нет).
3. Аватар: квадрат радиус 4, инициал 11/600, ink чёрный на цветном (`#000` через токен `accent-ink`). Цвета — только
   существующие токены; нужного токена нет — остановиться и спросить (правка — через handoff).
4. Автосохранение:
   - ключ = сущность и поле (`episode:c01:title`);
   - изменение сбрасывает таймер;
   - по таймеру `PATCH`, в полёте — индикатор «Сохраняю…», успех — «Сохранено ЧЧ:ММ» по ответу сервера;
   - новое изменение во время записи ставится в очередь, а не параллельно.
5. `beforeunload` предупреждает, только если есть несохранённое (`pending`) и сброс не успел.
6. Переименование обновляет кэш `useEpisode` и `useEpisodes` оптимистично. Ошибка сервера — откат названия и
   текст из `ApiError.message`.
7. Индикатор без открытого выпуска показывает последнее сохранение сессии или ничего — не выдуманное «12:41».
