## Цель

## Что сделать
1. Полоса берёт окно из `useSlots()`. Состояния не пересчитываются на фронте — только отображаются. Месяц окна —
   по датам: «сентябрь 2026», на стыке — «сентябрь — октябрь 2026».
2. Имя в ячейке — `short_title`, иначе название, обрезанное CSS (одна строка). Заметка — до двух строк, цветом
   статуса (`metaColor` артборда через токены).
3. Назначение и снятие — оптимистично с откатом. 409 и 422 бэкенда — тост с текстом `ApiError.message`, ячейка
   возвращается как была. После успеха — тост «Назначено на 23 сентября» или «Снято со слота».
4. Диалог:
   - `Dialog` кита, `useModalScope(open)` — иначе глобальные сочетания сработают сквозь него (хвост M1.4);
   - фокус при открытии — на выбранном канале; Esc и «Отмена» закрывают без изменений;
   - канал по умолчанию — текущий, в «Все каналы» — Cursus.
5. «Создать выпуск»:
   - `useCreateEpisode({channel, origin, slot: "next_free"})`;
   - кнопка в состоянии загрузки «Создаю…»;
   - успех → тост «Выпуск создан: Cursus, слот 23 сентября» (без слота — «слот не назначен»), `openEpisode`,
     переход на `paths.stage(id, 'script')`;
   - ошибка — текст под кнопками, диалог открыт.
6. «Из референса» в M3 создаёт выпуск с `origin: reference` — поле ссылки появится со сценарием (M4); пояснение в
   подсказке пункта, как в артборде.
7. Статус-строка экрана: середина — риск ближайшего будущего слота. Шаблон артборда: «Следующий слот 13 сентября,
   Pirate Ship: экспорт не запускался». Тот же текст, что в ячейке, — из `slotText.ts`; часть про SFX — с M8.
8. С клавиатуры: ячейки полосы — Tab по порядку; «Назначить выпуск» открывает меню стрелками; диалог — Tab по
   группам, радио — стрелками.
