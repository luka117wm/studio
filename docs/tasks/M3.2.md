# M3.2 — Слоты публикации и пресеты формата

**Модуль:** M3 — Выпуски и календарь слотов · **Оценка:** 4 ч · **Модель:** Opus · **План до кода:** да

## Цель
Бэкенд отдаёт полосу слотов «раз в два дня» с состояниями (занят, пуст, пропущен, сегодня, риск), назначает и снимает
выпуск со слота, при создании ставит выпуск в ближайший свободный слот и отдаёт пресеты формата с оценкой цены
выпуска.

## Что сделать
1. **Расписание.**
   - `data/schedule.json`: `{"anchor": "YYYY-MM-DD", "every_days": 2, "risk_days": 2}`.
   - Нет файла — `anchor` = сегодня, файл записывается при первом чтении. Слоты — `anchor + k × every_days` в обе
     стороны.
2. **Окно полосы.** `GET /api/slots?from=&count=11` — по умолчанию три прошлых слота и восемь будущих, как в
   артборде. Каждая строка:
   - `date`, `weekday`;
   - `episode_id`, `channel`;
   - `state`: `published | missed | today | filled | empty`;
   - `risk`: `null` или `{level: warning | failed, reason}`.
3. **Правила состояний** — в `docs/slots.md` и в тестах, с датой «сегодня», переданной параметром:
   - `today` — дата слота равна сегодняшней;
   - `missed` — прошлый слот без опубликованного выпуска, в том числе пустой прошлый;
   - `published` — у выпуска статус `published`;
   - `risk` — будущий слот ближе `risk_days` с выпуском не в `export`/`publish`, или статус `failed` / `warning`.
     `reason` — код (`script_not_ready`, `shots_incomplete`, `shots_failed`, `not_exported`), текст пишет фронт.
4. **Назначение.** `PUT /api/episodes/{id}/slot`:
   - дата не из расписания — 422 со списком ближайших слотов;
   - слот занят другим выпуском — 409 «Слот 23 сентября занят выпуском «…»; снимите его со слота или выберите
     другой»;
   - `null` — снять со слота;
   - повтор той же даты — 200.
5. **Ближайший свободный при создании.** `next_free` — первый будущий слот, начиная с сегодняшнего, без выпуска.
   Выбор и вставка — в той же транзакции, что id из M3.1: два одновременных «Создать» не получат один слот. Ответ
   `POST` содержит `slot_date` — тост «слот 23 сентября» берёт дату оттуда.
6. **Пресеты формата.** `config/formats.yaml` — значения из артборда и `CLAUDE.md`: Cursus — every rank, 18–25 мин,
   8 разделов, ~100 кадров; Otto — сутки в эпохе, 6–10 мин, 5 разделов, ~40 кадров. Проверка конфига при старте, как у
   `providers.yaml`: неизвестный формат, минимум больше максимума — ошибка старта.
7. **Оценка выпуска.** `GET /api/formats?channel=` суммирует оценки `Gateway.estimate` маршрутами профиля по
   умолчанию:
   - кадры × `images`;
   - символы VO (минуты × слов/мин × 6) × `voice`;
   - сценарий: `script` с `max_output_tokens` по объёму текста.

   Ответ: пресет + `estimate` (`Cost` со строками по этапам) + `stale_pricing`. Пересчёт — при каждом запросе.
8. **Типы:** `pnpm -C frontend typegen`, `typegen:check` зелёный.
