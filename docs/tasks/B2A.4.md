# B2A.4 — Экран канона

**Блок:** B2A — Канон · **Оценка:** 3 ч · **Модель:** Sonnet · **План до кода:** нет

## Цель
Канон канала редактируется в интерфейсе: стили, периоды, персонажи с обликами и листами портретов.

## Читать
- `design/Studio - 12 Канон.dc.html` — артборд экрана канона
- `design/CLAUDE.md`, `design/handoff/components.md`
- `backend/app/api/canon.py`
- `frontend/src/types/canon.ts`

## Создать / изменить
- `frontend/src/screens/canon/` — библиотека, редактор стиля, редактор периода, карточка персонажа, лист портретов
- `frontend/src/store/canonStore.ts`
- `frontend/src/api/canon.ts`

## Не трогать
- `frontend/src/engine/`, `frontend/src/timeline/`

## Что сделать
1. Три вкладки: Стиль, Периоды, Персонажи.
2. Стиль: поля канона, опорные кадры сеткой, история версий, диф двух версий.
3. Период: поля, список `forbidden` как редактируемые чипы, кнопка «создать из шаблона» (шаблон = близкий период).
4. Персонаж: `nature` сверху, ниже облики карточками с миниатюрой фаса, возрастом, периодом и статусом листа.
5. Действие «копировать облик в другой период» с явным списком того, что переносится и что нужно заполнить заново.
6. Лист портретов: шесть ракурсов, кандидаты, выбор, перегенерация ракурса, стоимость до запуска.
7. Предупреждение на обликах без готового листа: генерация кадров с ними заблокирована.

## Критерии приёмки
- [ ] создание периода и персонажа с двумя обликами проходит целиком через UI
- [ ] копирование облика переносит лицо и телосложение, очищает одежду и предметы
- [ ] облик без листа помечен, кнопка генерации кадров с ним недоступна
- [ ] Playwright-скриншот совпадает с макетом по раскладке

## Команды проверки
```bash
pnpm -C frontend test --run
pnpm -C frontend e2e -g canon
```

## Чего не делать
- не разрешать правку опубликованных версий
- не прятать `forbidden` в свёрнутую секцию: это то, что реально ломает эпоху
