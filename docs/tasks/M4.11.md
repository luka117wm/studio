**Модуль:** M4 — Идеи, сценарий и план через мост · **Оценка:** 4 ч · **Модель:** Sonnet · **План до кода:** да

## Цель
Вкладка «Референс» экрана 2 — по артборду:
- ввод ссылки и субтитров, разбор через мост;
- карта структуры на шкале времени;
- метрики со сравнением с нормой канала и приёмы подачи;
- сходство;
- «Новая тема по этой структуре» / «Своя версия этой темы».

Пункт «Из референса» в диалоге ведёт сюда, а на экране 3 у выпуска из референса видно сходство.

## Что сделать
1. **Ввод.**
   - Ссылка необязательна, субтитры обязательны.
   - Ошибка бэкенда «Не похоже на субтитры…» — под полем.
   - После сохранения: «Референс сохранён: 22:41, 412 реплик» и шаг моста «Скопировать промпт разбора».
2. **Состояния:**
   - нет референсов — пустое состояние с пояснением про субтитры;
   - сохранён, не разобран — мост;
   - разобран — карта, метрики, приёмы, действия.

   В шапке вкладки: «Референс разобран 11 сентября, 11:54».
3. **Карта структуры.**
   - Ширина сегмента пропорциональна длительности; узкие — подпись в Tooltip.
   - Цвет: `rank` — основной, `hook`/`promise`/`finale` — свои, `retention` — акцент; только токены.
   - Подписи времени — `formatDuration` (M3).
4. **Метрики** — подписи по артборду, числа из ответа бэкенда. «Средняя длина кадра» не выводится. Строка в
   `docs/visual_review.md`: «осознанно — нужно видео».
5. **Сходство** — плашка «Текст референса не переносится в сценарий. Перед утверждением проверяется сходство». По
   выпускам из этого референса: «3 %, норма, порог 10 %» или `warning` с фразами; плана нет — «плана ещё нет».
6. **Действия.** Создание выпуска → переход на экран 3, тост «Выпуск создан: Cursus, слот …». Пока разбора нет,
   кнопки выключены с подсказкой.
7. **Статус-строка вкладки:** «Референс: 22:41, 10 сегментов, сходство 3 %», «Текст референса в сценарий не
   переносится».
8. **Диалог.** «Из референса» больше не создаёт пустой выпуск, а ведёт на вкладку. Подпись пункта — «разобрать
   ролик на вкладке «Референс»».

## Критерии приёмки
- [ ] ввод субтитров: ошибка формата под полем; сохранение → мост разбора
- [ ] разобранный референс (мок): карта с 10 сегментами, шкала, метрики, приёмы
- [ ] `structureMap`: ширины суммируются в 100 %, узкие сегменты — подпись в Tooltip
- [ ] действия создают выпуск с режимом и ведут на экран 3; без разбора кнопки выключены
- [ ] диалог «Из референса» ведёт на вкладку; на экране 3 сходство показано у выпуска из референса
- [ ] `pnpm -C frontend test --run && lint && build`; hex в новых файлах нет
- [ ] вживую: свои субтитры → промпт → ответ настоящего чата → карта → «Своя версия этой темы» → экран 3 → план
      через мост → сходство в правой панели
