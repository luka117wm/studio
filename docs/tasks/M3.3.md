# M3.3 — Слой данных фронта и оболочка на API

**Модуль:** M3 — Выпуски и календарь слотов · **Оценка:** 4 ч · **Модель:** Opus · **План до кода:** да

## Цель
Оболочка (`TopBar`, `StageRail`, `StatusBar`, экран выпуска) берёт данные из `/api` через TanStack Query, события
SSE обновляют кэш, а при остановленном бэкенде приложение показывает понятную ошибку вместо пустоты. Фикстуры уходят
из оболочки.

## Что сделать
1. Ключи запросов — одно место (`queries.ts`), строки путей API — только там. Типы ответов — только `@/types/*`.
2. Сеть в тестах — `vi.stubGlobal('fetch')` с ответами из `mocks/api.ts`; `EventSource` — фейк из `sse.test.ts`
   (вынести в `api/__tests__/fakes.ts`). Числа в `mocks/api.ts` — как в артборде, иначе сверка скриншотов в M3.7 даст
   шум (приём M1.3).
3. `live.ts`:
   - снимок `GET /api/jobs` → `subscribe(onEvent, {lastEventId})`;
   - состояние джоба из события заменяет строку в кэше целиком;
   - конечные события инвалидируют `useEpisodes` и `useEpisode(id)` выпуска;
   - отписка — при размонтировании провайдера.
4. «Все каналы»: `useEpisodes('all')` без параметра канала; `TopBar` показывает сумму расходов. Открытие выпуска
   ставит его канал — правило в одном месте (`uiStore.openEpisode(episode)`).
5. Состояния оболочки по `design/CLAUDE.md`:
   - загрузка — скелетоны зон;
   - бэкенд недоступен (`ApiError.status === 0`) — `BackendState` на месте рабочей области, шапка без расхода;
   - ошибка 4xx/5xx конкретного запроса — текст `ApiError.message` в зоне, где он нужен.
6. `formatUsd`: микродоллары → «$61.40», единое правило округления с бэкендовым `format_usd` (тест на те же точки:
   0, <1¢, целые доллары). `formatPrice` кита пока не трогать — он для цены в кнопке с «~».
7. Заглушки экранов 2–12 импортируют только `mocks/placeholders.ts`; `grep` на `types/fixtures` пуст.
8. Экран 1 временно показывает пустое состояние, если выпусков нет, и простой список названий, если есть, — без
   фикстур. Доска — M3.5.
