# M1.3 — Оболочка и навигация

**Модуль:** M1 — Оболочка · **Оценка:** 5 ч · **Модель:** Opus · **План до кода:** да

## Цель
Приложение открывается в раскладке артбордов, по всем двенадцати экранам можно ходить, панели ведут себя правильно на трёх разрешениях.

## Читать
- `design/handoff/layout.md` — размеры панелей и поведение на 1536 / 1920 / 2560
- `design/handoff/README.md` — сквозной сценарий и неизменяемые правила
- `design/Studio - 1 Выпуски.dc.html` и `design/Studio - 5 Монтаж.dc.html` — раскладка двух крайних по сложности экранов
- `frontend/src/ui/index.ts`

## Создать / изменить
- `frontend/src/app/AppShell.tsx` — каркас: левая панель, шапка, рабочая область
- `frontend/src/app/router.tsx` — роутинг на все двенадцать экранов
- `frontend/src/app/providers.tsx` — QueryClientProvider, тема, тосты
- `frontend/src/screens/*/index.tsx` — двенадцать заглушек с правильными зонами
- `frontend/src/mocks/fixtures.ts` — данные пиратского выпуска
- `frontend/src/store/uiStore.ts` — состояние оболочки: активный канал, свёрнутость панелей
- `frontend/src/app/__tests__/shell.test.tsx`

## Не трогать
- `frontend/src/ui/**` — кит закрыт в M1.2, нужна правка — сказать, не чинить молча
- `frontend/src/styles/**`

## Что сделать
1. Раскладка строго по `layout.md`: ширины панелей, высота шапки, поведение при сужении. Числа брать оттуда, не с глаза по скриншоту.
2. Роутинг: маршруты соответствуют экранам 1–12, включая 12 «Канон». Прямой переход по URL работает, заголовок вкладки меняется.
3. Заглушки экранов — не пустые div: у каждого правильные зоны (левая колонка, центр, правая панель) с корректными размерами и `EmptyState` внутри. Это то, что позволит на следующих модулях наполнять экран, не двигая раскладку.
4. Фикстуры — реальный контент, не lorem ipsum: выпуск Cursus «Every Rank on a Pirate Ship», 19:48, 104 кадра, 3060 слов, расходы $61.40 из $150, ElevenLabs 212 400 из 600 000 символов, период «Карибы, 1716», пять обликов «You». Числа те же, что в макетах, — иначе при сверке скриншотов будет шум.
5. Типы фикстур положить в `src/types/` с шапкой «временные, заменяются генерацией из Pydantic на M2». Не выдумывать поля сверх того, что нужно оболочке.
6. TanStack Query подключить провайдером, но ни одного запроса не делать: данные берутся из фикстур напрямую. Query нужен, чтобы на M2 не переписывать дерево.
7. Zustand — только состояние оболочки (активный канал, свёрнутость панелей, активный выпуск). Доменные данные в стор не класть.
8. Проверить на трёх ширинах: 1536, 1920, 2560. Поведение — по `layout.md`, самодеятельности с брейкпоинтами не нужно.

## Критерии приёмки
- [ ] все двенадцать маршрутов открываются, прямой заход по URL работает
- [ ] ширины панелей совпадают с `layout.md` (проверить замером в devtools, не на глаз)
- [ ] на 1536 / 1920 / 2560 раскладка ведёт себя как описано
- [ ] переключение канала в шапке меняет контекст оболочки
- [ ] `pnpm -C frontend test` зелёный
- [ ] ни одного обращения к сети при загрузке (Network пустой, кроме ассетов)

## Команды проверки
```bash
pnpm -C frontend test --run
pnpm -C frontend dev   # пройти по всем экранам руками
```

- не реализовывать содержимое экранов: это следующие модули
- не поднимать бэкенд и не писать fetch
- не менять компоненты кита ради раскладки
