## Что сделать
1. **Идея** — поля:
   - `id` (`i0001`), `channel`, `title`, `angle`, `hook_promise`, `summary`;
   - `score` (0–100 или `null`), `score_reason`;
   - `source` (`manual | bridge`), `status` (`proposed | backlog | used | dropped`);
   - `episode_id`, `created_at`, `updated_at`.

   Название — непустое, до 200 знаков; тексты ошибок — по-русски (L-022).
2. **Переходы статуса:**
   - `proposed → backlog | dropped`;
   - `backlog → used | dropped`;
   - `dropped → backlog`;
   - `used` — конечный, ставит только создание выпуска.

   Неверный переход — 409 с текстом.
3. **Промпт идей.**
   - Контекст: канал, формат и пресет (минуты, разделы), семена ниши. Для запрета повторов — названия идей бэклога
     и выпусков канала; `count` идей (по умолчанию 6).
   - Чат возвращает `{"ideas": [{title, angle, hook_promise, summary, score, score_reason}]}` одним блоком
     ```json.
   - Оценка — мнение чата, а не данные. Так в промпте и в `docs/research.md`.
4. **Приём ответа.**
   - `extract_json` → проверка каждой идеи → сохранение `proposed`, `source: bridge`.
   - Ошибка в одной идее не роняет остальные: принятые сохраняются, ошибочные — в отчёте с номером.
   - Дубль названия с бэклогом или выпуском канала (без регистра) — пропуск с пометкой.
   - Обмен закрывается в `bridge_runs`.
5. **Создание выпуска из идеи** — `POST /api/episodes {channel, origin: "backlog", idea_id}`:
   - идея должна быть `backlog` этого канала, иначе 409 / 422;
   - заявка — `idea`, `angle`, `hook_promise` из идеи, `idea_id`;
   - стадия — `idea` (как в M3).
6. **Семена ниши** — список коротких строк, до 20, без дублей. Пустой список допустим — промпт тогда опирается на
   формат канала.

## Критерии приёмки
- [ ] CRUD идей и переходы статуса с текстами ошибок
- [ ] промпт идей совпадает с эталоном; бэклог и выпуски попадают в список «не повторять»
- [ ] ответ чата с 6 идеями, одна битая и одна дубль → 4 сохранены, отчёт называет обе пропущенные
- [ ] выпуск из идеи: название, заявка, стадия `idea`, идея `used`; из чужого канала или не из бэклога — отказ
- [ ] `uv run pytest && uv run ruff check . && uv run mypy backend tests`; `typegen:check`
