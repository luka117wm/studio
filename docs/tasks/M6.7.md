## Что сделать
1. **Раскладка** по `layout.md`: канон 280 (тянется 240–360, `⌥1`), центр `1fr`, «Голос» 320 (`⌥3`); полоса очередей
   72 над сеткой; статус-строка — «Кадры 78 из 104», вторая часть — отказы фильтра («2 кадра с отказом фильтра:
   s047, s071»).
2. **Пустые состояния** (`design/CLAUDE.md`, «Состояния»): план не утверждён — «Генерация начнётся после «Утвердить
   план»» со ссылкой на экран 3 (принцип 10); утверждён, картинок нет — главное действие «Сгенерировать 104 кадра
   (~$6.97)» с ценой из сметы пачки, отказ бюджета — текстом под кнопкой.
3. **Полоса очередей** — сводка пачки из API и SSE: готово, рисуется, в очереди; две части полосы прогресса (готово —
   белая, рисуется — штриховка), пауза — warning-треугольник и «на паузе». Отмена — `Dialog` с «Начатые кадры
   дорисуются».
4. **Канон выпуска** — данные `GET …/canon` (M5.10), только чтение; лист не готов — warning, как в артборде
   («лист не собран» пунктиром); подпись «Правка облика меняет опорные портреты и требует перерисовки затронутых
   кадров».
5. **Сетка** — 5 в ряд на 1536, 6 на 1920, 8 на 2560; заголовки разделов `sticky`. Плитка: миниатюра или фон
   статуса, номер кадра (у `failed` — цвет fail), глиф статуса по `design/CLAUDE.md`, точки версий («Версия 2 из 3,
   выбрана»). Длинные выпуски — без лагов: виртуализация разделов (`react-virtuoso`, уже в стеке), если 104 плитки
   дают заметный первый рендер.
6. **Живые данные** — прогресс по SSE без перезапроса всего; конец джоба кадра — миниатюра появляется в плитке;
   шапка расходов обновляется (L-046).
7. **Склонения** — «104 кадра», «21 кадр», «5 кадров» через общий `plural` (хвост «104 кадров» в заглушке).
8. **Моки и тесты** — экран на моках артборда; пауза и отмена шлют свои запросы; событие SSE двигает полосу.
