# M2.6 — Провайдеры, цены и бюджеты

**Модуль:** M2 — Бэкенд-фундамент · **Оценка:** 4 ч · **Модель:** Opus · **План до кода:** да

## Цель
Любой платный вызов идёт через единый слой: цена считается до постановки джоба, строка пишется в `cost_ledger`,
превышение бюджета — явный отказ; ключи Anthropic, Gemini и ElevenLabs проверяются живым тестом за центы.

## Что сделать
1. Единицы учёта: `image`, `char`, `second`, `token_in`, `token_out`, `search`; цена в `pricing.yaml` за единицу,
   `checked_at` обязателен; старше 60 дней — предупреждение в логе и поле `stale_pricing` в сводке.
2. `estimate` до постановки джоба возвращает `Cost {units, quantity, usd_micro, model}` — строку цены для кнопки
   собирает фронт из этого.
3. Строка журнала: время, провайдер, модель, этап, выпуск, `job_id`, единицы, количество, микродоллары, статус
   (`estimated | charged | cached | refused`).
4. Бюджеты трёх уровней; превышение → 409 «месячный лимит $150 исчерпан, потрачено $151.20; поднять лимит можно
   в настройках» — без тихого переключения на модель дешевле.
5. Профили качества меняют только маршрутизацию; ID моделей — только в `providers.yaml`; запрещённые модели
   (`gemini-2.5-flash-image`, Sora 2) валидатор конфига отклоняет.
6. Кэш: хэш входов по принципу 8 (для картинок — версии канона, промпт, референсы, модель, параметры, seed) — если в
   `assets` есть хэш и файл на диске, вернуть его и записать строку `cached`, $0.
7. Живые проверки ключей: `check()` каждого провайдера под маркером `live`; без ключа — `skip` с причиной, не `fail`.
   Anthropic — список моделей или минимальный запрос; Gemini — список моделей; ElevenLabs — `/v1/user/subscription`
   (заодно даёт квоту символов для шапки).
8. `docs/providers.md` и карта в `CLAUDE.md` (строка уже есть — сверить имена).

## Критерии приёмки
- [ ] фейковый провайдер: 10 вызовов → 10 строк в `cost_ledger`, сумма совпадает с ручным расчётом по `pricing.yaml`
- [ ] превышение бюджета → 409 с текстом, джоб не ставится
- [ ] смена профиля в `providers.yaml` меняет модель без правок кода; запрещённая модель в конфиге — ошибка старта
- [ ] повторный вызов с теми же входами — `cached`, $0
- [ ] `uv run pytest -m live` с ключами из `backend/.env` проходит для трёх провайдеров (центы); без ключей — skip

## Чего не делать
- не прошивать ID моделей и цены в код; не округлять в журнале — микродоллары
- не делать фолбэк на другую модель при отказе по бюджету
- не реализовывать генерацию картинок, голоса и сценария — только проверка ключей и оценка
