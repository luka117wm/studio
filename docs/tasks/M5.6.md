# M5.6 — Эпоха через мост: черновик и «Дополнить запреты»

**Модуль:** M5 — Канон · **Оценка:** 3 ч · **Модель:** Opus · **План до кода:** да

## Цель
Черновик эпохи пишет чат по id из плана и заявкам выпусков: материалы, свет, архитектура, одежда, предметы и
запреты. «Дополнить запреты» тем же мостом добавляет новые анахронизмы без повторов. Публикует человек.

## Что сделать
1. **Контекст промпта:**
   - id эпохи; заявки и названия выпусков канала, чьи планы на неё ссылаются (M5.2, «нужно каналу»);
   - формат канала; текущий черновик (если есть).
   Стиля канала в контексте нет: эпоха — факты, а не то, как выглядит картинка.
2. **Режим `draft`:** чат возвращает `label`, `region`, `years`, `palette_shift`, `materials`, `light_sources`,
   `architecture`, `clothing`, `props`, `forbidden` (не меньше 10). Ответ пишется в черновик и заменяет пустые поля.
   Заполненные человеком поля не затираются, а возвращаются списком «чат предложил иначе».
3. **Режим `forbidden`:** чат получает все текущие списки и возвращает только новые запреты. Приложение добавляет их
   без повторов (без учёта регистра и артиклей) и сообщает «добавлено N, повторов M».
4. **Приём ответа** — по правилам моста M4.1: ровно один JSON, проза вокруг допустима, ошибки по-русски с путём
   (`forbidden[3]`). Журнал `bridge_runs` с `target_id` = id эпохи.
5. **Стоп-лист** (`load_stoplist`) — на все поля эпохи: стилевой токен — отказ с полем и словом. Принцип 13: стиль
   задаёт только стиль канала.
6. **Шаблон** — английский. Описание эпохи и запреты — тоже: они уходят в промпт картинки. Правило «не цитировать»
   здесь не нужно, правило «только факты эпохи, без описаний рендера» — нужно. Эталоны промптов — в
   `tests/fixtures/prompts/`, `version` поднимается с каждой правкой текста (как в M4).
7. **Тесты:**
   - эталоны обоих режимов;
   - черновик из ответа с прозой;
   - ручные поля не затираются;
   - дополнение без повторов;
   - стилевой токен — отказ;
   - журнал обменов;
   - мост не пишет в `cost_ledger` (решение 1 устава M4).
