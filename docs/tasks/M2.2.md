# M2.2 — Контракт director.json

**Модуль:** M2 — Бэкенд-фундамент · **Оценка:** 4 ч · **Модель:** Opus · **План до кода:** да

## Цель
Pydantic-модель плана съёмки по скелету из `CLAUDE.md`, из неё генерируются JSON Schema и документация, фикстура
пиратского эпизода на 10 кадров проходит валидацию, четыре битые — падают с сообщением по кадру.

## Читать
- `CLAUDE.md` — «Данные: три уровня — три роли» целиком, включая скелет JSON и принцип 13
- `backend/app/settings.py`, `backend/app/api/__init__.py`
- `frontend/src/types/fixtures.ts` — какие поля уже ждёт оболочка (не расширять контракт ради них — сверить имена)

Больше ничего не открывать. Нужен файл вне списка — сначала сказать.

## Что сделать
1. Модели строго по скелету: `canon_ref` (ссылки на версии стиля, периодов, обликов), а не блок `canon`; таймингов нет.
2. Литералы вместо строк: `shot_size`, `motion.type` (8 вариантов из инспектора: push_in, pull_out, pan_left, pan_right,
   tilt_up, tilt_down, static, drift), `motion.ease`, `transition.type` (cut | crossfade | dip), `reference_mode`,
   `fact.status`, `meta.format` (every_rank | host).
3. Диапазоны: `motion.strength` 0…0.25, `transition.duration` 0…1.5, `sfx.gain_db` −40…0, `music.gain_db` −40…0,
   `target_minutes` 1…40, `animate.seconds` 2…10, `pace_wpm` 100…200.
4. Правило частей: `meta.part` / `parts_total`; при `part > 1` блоки `canon_ref` и `voice` необязательны и при
   импорте берутся из части 1 (сам мёрдж — M2.4).
5. Доменные проверки: уникальность `shot.id` и `section.id`; `shot.section` существует; `vo` непустой; `animate.prompt`
   обязателен при `animate.recommended = true`; `image.appearances` и `image.period` ссылаются на ключи `canon_ref`;
   `music[].section` существует; `shot.image.prompt` не содержит токенов стоп-листа (регистронезависимо, по словам).
6. Сообщения: `кадр s047: <что не так>, ожидалось <что>` — русский, без стектрейсов; список всех ошибок разом, не первая.
7. `gen_schema.py` (`uv run python -m app.tools.gen_schema`) — детерминированный вывод, `$id`, версия схемы
   `studio.director/1`.
8. `docs/director_schema.md` по факту моделей; `CLAUDE.md` уже ссылается на эти файлы — имена не менять.
9. Фикстуры: пиратская — реальные VO и промпты (действие и композиция, без стиля), 2 раздела, `canon_ref` на
   `style/v003`, `periods/caribbean-1716/v002`, `characters/you/v004#powder-monkey-11`.
10. Тесты: валидная проходит; каждая битая падает с ожидаемым фрагментом текста; схема регенерируется без диффа.
