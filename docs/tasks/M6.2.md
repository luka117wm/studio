# M6.2 — Джоб кадра `shot_image`: сборщик → шлюз → версия

**Модуль:** M6 — Генерация · **Оценка:** 4 ч · **Модель:** Opus · **План до кода:** да

## Цель
Один кадр выпуска рисуется джобом: запрос собирает сборщик M5.5, оплачивает шлюз, картинка становится новой
версией кадра. Повтор того же запроса не платится, отказ модели — `failed` с причиной, модель выбирается из
каталога `images`.

## Что сделать
1. **Заказ** собирается при постановке: проверка, что план утверждён (принцип 10: генерация только после «Утвердить
   план»), кадр в действующем плане, `problems` сборщика пуст. Иначе — 409 со списком проблем и их адресатами
   (`PromptProblem.canon`, хвосты M5).
2. **Вариант.** Вариант 1 даёт тот же хэш, что показал предпросмотр (тест на равенство `input_hash`). Следующий
   вариант меняет только seed. Номер варианта — в payload: перезапуск после аварии рисует тот же вариант.
3. **Деньги** — `estimate` по маршруту `images` выбранной модели; бюджет выпуска и месяца до постановки (409
   `BudgetRefusal`), шлюз проверяет снова в момент вызова. Строка `cost_ledger` — этап `images`, выпуск, кадр, джоб.
4. **Кэш с привязкой (L-042).**
   - У кадра уже есть версия с этим хэшем (тот же вариант и модель) — джоб возвращает её, новой версии нет,
     вызова и денег нет (идемпотентность после аварии).
   - Хэш есть в кэше, но не среди версий кадра (нарисован в другом выпуске, строка `assets` потеряна) — шлюз даёт
     `cached`, и ассет становится новой версией кадра, как оплаченный: файл копируется в `media/<кадр>/`,
     `cached: true`, $0. Тест на оба случая.
5. **Отказ модели.** `ProviderError` (фильтр безопасности, 4xx) — кадр `failed`, причина — в новом поле
   `ShotState.error` (одна строка по-русски: что случилось и что сделать), без повтора. `TransientError` — повтор очереди по
   `docs/jobs.md`. `BudgetExceeded` в момент вызова — `failed` с текстом бюджета.
6. **Модель** — `override` в `registry.resolve` по ключу каталога; не из каталога — 422 со списком. Версия помнит
   ключ и ID модели.
7. **Каталог для экрана** — `GET /api/providers/catalog/images`: подписи, цены единицы ($0.067, $0.034, $0.134),
   профиль по умолчанию. Цены — только из `pricing.yaml` (принцип 5).
8. **Прогресс** — «Кадр s047 · рисуется», в конце `result`: `{shot_id, version, status, usd_micro}`.
