## Цель
Шлюз умеет заказать картинку у Gemini — с референсами, по цене из `pricing.yaml`, со строкой в `cost_ledger`.

## Что сделать
1. **Вызов Gemini для картинки:**
   - промпт, negative (как модель его принимает — по документации), референсы картинками, seed, размер из `params`
     маршрута;
   - ответ — байты PNG и `usage` (1 картинка нужного размера);
   - ошибки — через `status_error()` с телом ответа: смысл в теле, а не в статусе (L-018). Отказ модели по
     содержанию — понятное сообщение, а не 500;
   - сеть — `TransientError`, ретраи — по правилам M2.6.
2. **Референсы:**
   - запрос несёт пути файлов, ключ кэша — их хэши (`ImageRequest.refs` уже хранит хэши, принцип 8);
   - провайдер получает байты, шлюз проверяет, что файлы есть;
   - больше лимита модели — `RouteError` до вызова, без тихой обрезки.
3. **Ассеты уровня канала:**
   - `CallContext(channel=…, stage="anchors")` без выпуска;
   - файл — в каталог канона канала (путь задаёт вызывающий: `canon/anchors/…`; по умолчанию — `canon/cache/<этап>/`);
   - миграция — ассет без выпуска; вариант (`channel` в `assets` с `episode_id NULL` или отдельная таблица) выбрать
     в плане этапа. Кэш по `(kind, input_hash)` одинаков для обоих уровней.
4. **Деньги:**
   - строка `cost_ledger` с каналом и этапом `anchors`, без `episode_id`;
   - `check_budget` для вызова канала проверяет только месячный бюджет канала. Превышение — отказ до вызова.
     Лимиты выпуска и анимации не применяются;
   - повтор с теми же входами — `cached`, $0, файл тот же.
5. **Этап `anchors` в `providers.yaml`** — каталог с одной моделью Pro во всех профилях: эталон внешности делается
   один раз. Лимит референсов модели — поле маршрута (14 у Pro по документации — сверить), его читает сборщик M5.5.
6. Фейковый транспорт Gemini в тестах — как у `check` (M2.6). Сеть не нужна.
7. Живой тест `-m live -k anchors`: одна картинка 1K с одним референсом, файл не пустой, PNG, строка расхода.
   Запуск — вручную, центы.
8. `docs/providers.md` — этап `anchors`, вызов без выпуска, референсы и лимит, что пишется в ledger.

## Критерии приёмки
- [ ] `uv run pytest` зелёный: вызов, ошибки по телу, референсы в ключе кэша, лимит референсов, ассет канала, кэш $0,
      бюджет канала
- [ ] `uv run ruff check . && uv run ruff format --check . && uv run mypy backend tests`
- [ ] `uv run pytest -m live -v -rP -k anchors` — одна настоящая картинка, строка в `cost_ledger` (центы; запуск
      после согласия пользователя)
