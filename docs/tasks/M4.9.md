## Что сделать
1. **Канал** — из `uiStore.channel`. В «Все каналы» экран просит выбрать канал: идеи и семена — свои у каждого
   (правило 6 handoff).
2. **Семена.** Добавить (Enter), убрать (×), не больше 20, дубль — подпись под полем. Сохранение сразу, тост не
   нужен — видно по чипам.
3. **Идеи из чата.**
   - Копирование и вставка — как на экране 3.
   - Отчёт приёма: «Добавлено 4 идеи, пропущено 2» со списком причин.
   - Карточка: название 13/500, оценка, «почему» мелко, описание.
4. **«В бэклог»** — PATCH статуса, карточка уходит в центр. **«Начать выпуск»** — создание выпуска из идеи:
   - из `proposed` — сначала `backlog`, потом создание;
   - переход на экран 3 выпуска, тост «Выпуск создан: Cursus, слот …» (как в M3.6).
5. **Бэклог.** Сортировка — по оценке, потом по дате; «Убрать» → `dropped`, видно в фильтре «Убранные» с действием
   «Вернуть».
6. **Статус-строка:** «Идей в бэклоге 7, слот 21 сентября свободен» — ближайший пустой слот из `useSlots`.
7. **Диалог «Новый выпуск».** Пункт «Из бэклога идей» с выбранной идеей создаёт выпуск с `idea_id`. Подпись пункта
   — «7 идей» по выбранному каналу. Кнопка «Из бэклога идей» на доске (M3.5) ведёт на экран идей.
