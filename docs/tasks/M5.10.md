# M5.10 — Канон на экране «Сценарий и план»

**Модуль:** M5 — Канон · **Оценка:** 3 ч · **Модель:** Sonnet · **План до кода:** да

## Цель
На экране 3 видно, к каким версиям канона прибит выпуск и чего не хватает для утверждения. Выпуск можно перевести на
новые версии, у любого кадра открывается итоговый промпт с источниками секций и референсами. Отказ утверждения ведёт
на экран 12.

## Что сделать
1. **«Канон выпуска»** — секция правой панели (над сметой):
   - стиль, эпохи и облики плана: прибитая версия, статус — готов / нет версии / только черновик / есть новее;
   - у облика — статус листа;
   - каждая строка — ссылка на сущность экрана 12 (`/canon?layer=periods&id=…`, `?sheet=…`).
2. **«Перевести на новые версии»** — видна, когда есть новее:
   - подтверждение со списком «эпоха venice-1570: v001 → v002» и предупреждением «затронутые кадры станут
     `stale`, картинки останутся»;
   - результат — тост с новой версией плана, на листе причины `stale`.
3. **Предпросмотр промпта кадра:**
   - вход — у строки движения на правом поле листа и в строке таблицы;
   - содержимое — секции с источником (`style/v003`, `periods/caribbean-1716/v002`, `characters/you/v004#…`,
     `кадр`), итоговый текст, negative, референсы с подписями, seed, модель и цена кадра;
   - проблемы канона — списком вместо промпта, со ссылками на экран 12.
4. **Отказ «Утвердить план» с `check: canon`** — сводка бэкенда и список «эпоха … не опубликована», «облик …: лист 3/6»
   со ссылками на экран 12. Утверждение доступно после публикации и листов.
5. **Статус-строка экрана 3:** «Канон: 2 из 5 обликов без листа», если канон не готов.
6. **Тесты:**
   - секция со статусами и ссылками;
   - перевод — подтверждение, запрос, тост;
   - предпросмотр с источниками;
   - проблемы канона в предпросмотре;
   - отказ утверждения со ссылками;
   - выпуск без проблем канона — секция «готов».
