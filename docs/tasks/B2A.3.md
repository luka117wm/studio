## Что сделать
1. Порядок секций фиксирован: `style_block` → `period_block` → `appearance_block` (по каждому персонажу кадра, в порядке `shot.image.appearances`) → `action` (`shot.image.prompt`) → `shot_size` → `composition_rules`. Negative собирается объединением `negative_global ∪ period.forbidden ∪ appearance.negative_local` с дедупликацией и стабильной сортировкой.
2. Референсы: опорные портреты всех обликов кадра + 2 опорных кадра стиля. Порядок стабильный, количество ограничено лимитом модели; при переполнении первыми отбрасываются кадры стиля, портреты — никогда.
3. Стоп-лист: если `shot.image.prompt` содержит стилевой токен — ошибка валидации с указанием слова и объяснением «стиль задаётся каноном, опишите только действие». Стоп-лист в отдельном файле, пополняется по мере встреч.
4. Детерминированность: один и тот же кадр при неизменных версиях канона даёт побайтово идентичный промпт. Тест на 20 кадрах фикстуры.
5. Seed: детерминированный от хэша (episode_id, shot.id, версии канона) — перегенерация без изменений даёт тот же кадр.
6. Предпросмотр в UI: пользователь видит итоговый текст и список референсов до траты денег.
7. Секции промпта помечены в предпросмотре источником (стиль / период / облик / действие), чтобы было видно, откуда что приехало.
