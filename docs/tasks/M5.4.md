# M5.4 — Листы опорных портретов и кадры стиля

**Модуль:** M5 — Канон · **Оценка:** 5 ч · **Модель:** Opus · **План до кода:** да

## Цель
У каждого облика есть лист из шести отобранных опорных портретов, а у стиля — шесть опорных кадров. Сборка идёт
джобом с ценой до клика. Лист следит за версией облика и устаревает, когда меняется внешность.

## Что сделать
1. **Промпт ракурса собирает код:** стиль (версия канала) + эпоха облика + облик (`nature`, `face`, `build`, `hair`,
   `clothing`, `wear`, `props`) + строка ракурса из `config/canon.yaml`. Фон нейтральный, свет ровный. Negative —
   `negative_global ∪ forbidden ∪ negative_local`. Порядок секций фиксирован.
2. **«Собрать лист»** — джоб `anchor_sheet` (решение 5):
   - сначала 2 кандидата фаса, затем 5 ракурсов × 2 с первым фасом как референсом;
   - seed — хэш (облик, версия, ракурс, номер кандидата);
   - кандидаты — в `canon/anchors/<appearance>/candidates/`;
   - прогресс — по кандидатам, по SSE;
   - сбой одного кандидата — `failed` у кандидата, остальные идут (принцип 7);
   - отмена работает.
3. **Цена до клика:** `GET …/anchors/estimate` — лист, ракурс, кадры стиля, по `gateway.estimate`. Бюджет канала —
   до постановки, превышение — 409 с текстом (решение 6).
4. **Выбор и отбраковка:**
   - `POST …/anchors/{angle}/choose {candidate}` пишет `chosen.json`: ракурс → файл, seed, версия облика, дата, цена;
   - `POST …/anchors/{angle}/reject {candidate}` переносит файл в `rejected/`, ничего не удаляется.
5. **Перегенерация ракурса** — джоб `anchor_angle`: 2 новых кандидата одного ракурса с выбранным фасом как
   референсом. Остальные пять ракурсов не меняются (тест по хэшам файлов).
6. **Состояние листа** — `GET …/appearances/{id}/anchors`:
   - ракурсы с кандидатами и выбором, `ready` (6/6), цена собранного;
   - `stale` с причиной — по сравнению версии облика в `chosen.json` с текущей опубликованной (решение 5): другие
     `face` или `build` — весь лист, другие `clothing` или `props` — три ракурса;
   - то же отдаётся в «канон выпуска» M5.2.
7. **Копия облика в другую эпоху** — `POST …/appearances/{id}/copy {period, appearance_id}` в черновик персонажа:
   `face` и `build` побайтово, одежда, предметы и износ пустые, листа нет.
8. **Кадры стиля** — джоб `style_anchors`: 6 шаблонов из `config/canon.yaml` × эпоха, выбранная при сборке, по одному
   кандидату. Файлы — в `canon/anchors/style/`, привязаны к версии стиля, устаревают при смене рендера, оптики или
   света.
9. **Тесты** (фейковый Gemini):
   - лист из 12 кандидатов, фас — референсом для остальных;
   - выбор → `chosen.json`, отбраковка → `rejected/`;
   - перегенерация одного ракурса не трогает другие;
   - устаревание по `face` и по `clothing`;
   - копия облика сохраняет `face`;
   - повторная сборка — из кэша, $0;
   - бюджет канала — отказ без вызова;
   - строка `cost_ledger` этапа `anchors`.
