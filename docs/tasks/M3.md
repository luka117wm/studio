# M3 — Выпуски и календарь слотов

Третий модуль. Составлен 2026-09-26 по `STATUS.md` (итоги M2, разделы 16–18), артборду
`design/Studio - 1 Выпуски.dc.html`, `design/handoff/` и хвостам M1. Оценка: 24–26 часов, семь этапов, семь сессий.
Ветка `m3-episodes` от `main` после слияния PR #1 (пока PR открыт — от `m2-backend`), тег `m3` на выходе.

**Что на выходе.** Первый экран на настоящих данных. Экран «Выпуски» показывает доску по стадиям, полосу слотов
публикации и диалог «Новый выпуск» поверх `/api`. Оболочка тоже на API: `TopBar` с `ChannelSwitcher` (аватар,
«Все каналы»), инлайн-переименованием выпуска и индикатором автосохранения; `StageRail` по стадии выпуска;
`StatusBar` с живым процессом из SSE и риском ближайшего слота. Бэкенд умеет:
- создавать выпуск без ручного id;
- переименовывать выпуск;
- назначать слот по расписанию «раз в два дня»;
- отдавать сводку для карточки: кадры, длительность, расход, текущий джоб;
- отдавать пресеты формата с оценкой цены выпуска.

Фикстуры M1 уходят из оболочки и экрана 1. E2E идёт на моках API, эталоны пересняты осознанно и сверены с артбордом.

**Чего на выходе нет и не должно быть.**
- Миниатюр кадров на карточках: плейсхолдер, картинки появятся в M6 вместе с отдачей медиа.
- CTR и просмотров у опубликованных: M10.
- Бэклога идей: M4. Пункт «Из бэклога идей» в диалоге виден, но выключен с пояснением.
- Ручной смены стадии и перетаскивания карточек между колонками: стадия меняется действиями пайплайна.
- Квоты ElevenLabs в интерфейсе: на экране 1 её нет, показ — в M11. Данные уже есть в `GET /api/providers/status`.
- `strings.ru.ts`: хвост остаётся за сессией правок handoff.
- Экраны 2–12 не наполняются: они остаются заглушками.

## Решения модуля

Приняты при составлении, чтобы этапы не спорили о них заново.

1. **Стадия, статус, колонка доски.**
   - `episodes.stage` — где выпуск в пайплайне: те же шесть этапов, что на рельсе (`idea … publish`).
   - `episodes.status` — его здоровье: `queued | generating | warning | ready | failed | published`.
   - Колонку доски (Идея, Сценарий, Генерация, Монтаж, Готов к публикации, Опубликован) вычисляет одна чистая
     функция фронта из стадии и статуса, с тестом. Отдельного поля нет.
   - Стадию меняют действия следующих модулей («Утвердить план» → `generate` и т. д.). В M3 её ставит только
     создание выпуска.
2. **Выпуск создаётся без id и названия.** Диалог артборда не спрашивает ни то, ни другое.
   - Сервер выдаёт id вида `c08` / `o05`: инициал канала плюс номер по порядку в канале. Id — имя каталога, после
     создания он не меняется.
   - Название-заготовка — «Новый выпуск». Переименование — инлайн в `TopBar`, id не трогает.
   - Явный id (как `c07-pirate-ship` в фикстурах) по-прежнему принимается.
3. **Слоты — одно расписание на оба канала.** Цель продукта — выпуск раз в два дня на пользователя, в артборде
   Cursus и Otto чередуются в одной полосе.
   - Расписание: `data/schedule.json` — `{anchor, every_days: 2, risk_days: 2}`. Файл пишется атомарно, правка — в
     M11; до неё правится руками или остаётся по умолчанию.
   - В слоте один выпуск, занятый слот — 409. Состояния слота (занят, пуст, пропущен, сегодня, риск) считает
     бэкенд.
   - «Сегодня» — локальная дата машины: бэкенд и браузер на одном ноутбуке.
4. **«Все каналы» — режим просмотра, не третий канал.** Доска и полоса слотов показывают оба канала, чужие слоты
   приглушены. Открытие выпуска переключает канал на канал выпуска — каналы изолированы (правило 6 handoff).
   Фильтр «Все / Cursus / Otto» в заголовке экрана и `ChannelSwitcher` — одно состояние (`uiStore.channel`).
5. **Пресеты формата — конфиг, оценка — через gateway.**
   - `config/formats.yaml`: минуты, разделы, кадры, голос для `every_rank` и `host`. Его же возьмёт M4 для сметы и
     промпта.
   - «~$3.80 за выпуск» считает `Gateway.estimate` по маршруту профиля по умолчанию, не константа в тексте
     (принципы 5, 6).
6. **Данные фронта — TanStack Query, не стор.**
   - `uiStore` держит только канал, открытый выпуск, панели, тосты и состояние автосохранения.
   - События SSE обновляют кэш запросов: выпуск, сводку, джобы.
   - Автосохранение одно на приложение: дебаунс 800 мс, сброс при уходе со страницы, `SaveIndicator` в шапке. В M3 его
     первый потребитель — переименование, в M4 — сценарий.
7. **Фикстуры.** Оболочка и экран 1 — только API.
   - `types/fixtures.ts` удаляется.
   - `mocks/fixtures.ts` сжимается до `mocks/placeholders.ts`: примерные цены пустых состояний экранов 2–12. Файл
     уходит по частям вместе с модулями этих экранов.
   - Контент артборда переезжает в `mocks/api.ts` — ответы API, проверенные сгенерированными типами (`satisfies`).
     Им пользуются vitest и e2e (`page.route`), production-код — нет.
8. **Эталоны e2e переснимаются один раз — в M3.7.** Меняется шапка всех экранов, поэтому эталоны меняются тоже.
   Пересъёмка сопровождается сверкой с артбордом 1 и строками в `docs/visual_review.md`. До M3.7 e2e по шапке и
   экрану 1 может быть красным — это ожидаемо; остальные экраны зелёные.

## Приёмка M3 целиком

Перед `git tag m3`:

- [ ] семь этапов закрыты, коммит на каждый
- [ ] `uv run pytest && uv run ruff check . && uv run mypy backend tests` — зелёные
- [ ] `pnpm -C frontend test --run && lint && build && typegen:check && e2e` — зелёные; эталоны пересняты только в
      M3.7, каждое изменение — строка в `docs/visual_review.md`
- [ ] `types/fixtures.ts` удалён; `grep -rn "mocks/fixtures\|types/fixtures" frontend/src` пуст; оболочка и экран 1
      не импортируют `mocks/` (данные тестов и e2e — `mocks/api.ts`)
- [ ] вручную, `./run.sh` + `python -m app.tools.seed`:
  - «Новый выпуск» → Cursus, «С нуля» → «Создать выпуск» → тост «Выпуск создан: Cursus, слот …» и переход в сценарий;
    на доске — карточка в колонке «Сценарий», в ближайшем свободном слоте — выпуск, на диске —
    `data/projects/cursus/c01/project.json`;
  - переименование в шапке → индикатор «Сохраняю» → «Сохранено ЧЧ:ММ»; после перезагрузки страницы новое имя на
    месте;
  - назначение выпуска в пустой слот и снятие со слота работают; занятый слот — сообщение бэкенда, а не молчание;
  - `curl -X POST localhost:8000/api/jobs -d '{"kind":"sleep_job",…}'` → в статус-строке живой процент, после
    `done` строка очищается;
  - «Все каналы» показывает оба канала, выбор Otto прячет карточки Cursus и приглушает его слоты; открытие выпуска
    Cursus из режима «Все каналы» переключает шапку на Cursus;
  - бэкенд остановлен → экран показывает ошибку «что случилось и что сделать», без вечных скелетонов; бэкенд
    поднят → «Повторить» восстанавливает экран.
- [ ] хвосты M1 и M2, закрываемые модулем: `ChannelSwitcher` и «Все каналы», переименование выпуска,
      `Episode.stage/status`, `formatUsd` для микродолларов — закрыты; `ProjectPatch` перенесён в M4,
      `voice_quota` — в M11 (оба с причиной в `STATUS.md`)
- [ ] `STATUS.md` обновлён: «Сделано» пополнен, «Дальше» начинается с сессии правок handoff, затем M4
- [ ] `docs/LESSONS.md` пополнен, если были грабли (кэш запросов против событий SSE, дебаунс против навигации —
      вероятные кандидаты)
