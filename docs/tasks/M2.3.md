**Модуль:** M2 — Бэкенд-фундамент · **Оценка:** 3 ч · **Модель:** Sonnet · **План до кода:** нет

## Цель
Выпуск создаётся на диске в дереве из `CLAUDE.md`, `project.json` читается и пишется атомарно и переживает аварийное
завершение, схема SQLite накатывается миграциями, каналы и выпуски отдаются по API.

## Что сделать
1. `paths.py` по дереву `CLAUDE.md`: `data/channels/<channel>/{profile.json,oauth/,canon/}` и
   `data/projects/<channel>/<episode>/{director/,project.json,media/,cache/,exports/,publish/}`. Ни одной склейки путей
   вне этого файла; только `pathlib`, никаких `/mnt/c` и обратных слешей.
2. `atomic.py` + тест: 500 записей подряд, в случайной итерации исключение внутри записи — файл на диске всегда валидный
   JSON, старой или новой версии (L-003).
3. Миграции: SQL-файлы по номеру, таблица `schema_version`, повторный запуск идемпотентен; одно соединение на запрос
   через зависимость, `check_same_thread=False` не использовать — соединение на поток.
4. `channel.py` и `seed.py`: профили каналов с бюджетами и квотой голоса (числа — как в фикстурах оболочки, чтобы M3 не
   спорил с макетом), каталоги `canon/` и `oauth/` — пустые не создавать, только `profile.json`.
5. `project.py`: ассеты `{id, kind, version, path, hash, status}`, тайминги `{shot_id, start, duration, source: voice|locked|estimate}`,
   `*_locked`, `user_override`, `director_version`, стоимость по этапам в микродолларах. Время — float секунды.
6. API каналов и выпусков; `POST /api/episodes` создаёт запись в `episodes`, дерево на диске и пустой `project.json`;
   `PATCH /api/projects/{id}` мёрджит частичное обновление и пишет атомарно.
7. Дебаунс автосохранения — на фронте (M3); бэкенд просто пишет быстро и атомарно.

## Критерии приёмки
- [ ] `POST /api/episodes` создаёт дерево папок и `project.json`; повторный `POST` с тем же id — 409
- [ ] тест прерванной записи проходит 500 итераций
- [ ] `migrate()` дважды подряд — без ошибок и без изменений схемы
- [ ] `PATCH /api/projects/{id}` с одним полем не затирает остальные
- [ ] `GET /api/channels` отдаёт `cursus` и `otto` после `seed`
