## Что сделать
1. **JSON.**
   - Открывается текст текущей версии (`GET …/director/vNNN`), отформатированный в 2 пробела.
   - Ввод → проверка без записи с дебаунсом 800 мс; ошибки и строки с ними обновляются.
   - Синтаксическая ошибка JSON ловится на фронте: строка и столбец, запрос не уходит.
2. **«Сохранить как версию»** (secondary — primary на экране один):
   - выключена, пока есть ошибки или текст не менялся;
   - успех — тост «Сохранено как v004» и переход в режим «Сценарий»;
   - хэш совпал — тост «Совпадает с v003, новая версия не создана».
3. **Несохранённый JSON.** Уход из режима или со страницы с правками — предупреждение (как `AutosaveGuard`, M3.4).
4. **Факт-чек.** Без фактов — строка «Чат не прислал фактов на проверку».
5. **Смета** — до клика (принцип 6):
   - строки кадров, голоса и анимации; «План — мост через чат, $0»;
   - итог «~$13.40»;
   - «Останется $75.20 из месячных $150»;
   - предупреждения цветом `warning`.
6. **Утверждение.**
   - Кнопка выключена, пока нет плана или не собраны части.
   - 409 — список проблем со ссылками на кадры.
   - После успеха кнопка меняется на «План v003 утверждён», а если текущая версия новее утверждённой — «Утвердить
     снова».
   - Строка артборда «Утверждение доступно, кадр уйдёт в очередь последним» противоречит решению 8. Строка в
     `docs/visual_review.md`: «осознанно».
7. **Рельс этапов и доска** после утверждения показывают «Генерацию»: инвалидация списков (M3.3).

## Критерии приёмки
- [ ] JSON: ошибка синтаксиса — строка и столбец без запроса; доменная ошибка — подсветка строки кадра, клик
      ведёт к ней
- [ ] «Сохранить как версию» — тост с номером; совпадение хэша — свой тост
- [ ] факт-чек: три статуса, ссылка, переход к кадру
- [ ] смета: строки, итог, остаток; утверждение: 409 со списком, успех с переходом стадии (моки)
- [ ] `jsonHighlight` — таблица случаев (вложенность, экранирование, юникод)
- [ ] `pnpm -C frontend test --run && lint && build`; hex в новых файлах нет
- [ ] вживую: план из чата → правка в JSON → `v002 · manual` → «Утвердить план» → стадия «Генерация» на рельсе и
      доске
