# Визуальная приёмка M1 (2026-09-19)

Попарная сверка приложения с артбордами `design/Studio - N *.dc.html` на 1536 (артборды существуют только в этой
ширине; 1920 и 2560 — по `layout.md`). Сверялись раскладка зон, ширины панелей (замер DOM в обоих), плотность,
кегли, отступы; цвета — по переменным `tokens.css` (hex артбордов → токены по `design/CLAUDE.md`).
Содержимое экранов (карточки, таблицы, формы) — не дефект: его ещё нет. Регрессия: `pnpm -C frontend e2e`,
44 эталона в `frontend/e2e/__screenshots__/` (11 экранов × 3 ширины + оверлеи и 8 вкладок каталога на 1536).

Решения: **исправлено** — в коде этой сессии (коммит M1.6); **осознанно** — отличается, причина указана;
**макет** — требует правки макета или handoff; **совпадает** — после правки handoff.
