# Канон канала: схемы, черновики, версии, ссылки

Контракт M5.1. Модели — `backend/app/models/canon.py`, хранилище — `backend/app/storage/canon_store.py`, API —
`backend/app/api/canon.py`. TS-типы — `frontend/src/types/canon.ts` (ответы) и `canon_draft.ts` (тела `PUT`),
генерируются `pnpm -C frontend typegen`. Сборка промпта из канона — `docs/prompt_assembly.md` (M5.5).

Канон — визуальная константа уровня канала, а не выпуска (`CLAUDE.md`, «Данные»; принципы 13 и 14). Три слоя,
каждый версионируется отдельно: стиль канала, эпохи, персонажи с обликами. План выпуска канон не содержит —
только ссылки `canon_ref` на версии.

## Хранение

```
data/channels/<channel>/canon/
  style/                    v001.json  v002.json …  draft.json
  periods/<period_id>/      v001.json …             draft.json
  characters/<character>/   v001.json …             draft.json     один файл на персонажа со всеми обликами
  anchors/<appearance_id>/  candidates/  rejected/  chosen.json    листы портретов — M5.4, в M5.1 только пути
  anchors/style/                                                   опорные кадры стиля — M5.4
```

- **Версия** `vNNN.json` (`v001`…`v999`) неизменяема. Пишется только новым файлом: temp → fsync → `os.link` →
  unlink temp (`storage/atomic.py::write_json_new`). Если файл уже есть — отказ, а не замена. Версии не правятся
  и не удаляются.
- **Черновик** `draft.json` — один на слой или сущность. Пишется атомарно поверх (L-003). Проверяется только
  форма (422), правила публикации — нет.
- Каналы изолированы: всё лежит под `data/channels/<channel>/`, канон одного канала другому не виден.

Конверт файла:

```jsonc
// vNNN.json
{ "based_on": "v001",            // версия, из которой начат черновик; null — с нуля
  "published_at": "2026-10-14T12:00:00+00:00",
  "data": { … } }                // Style | Period | Character
// draft.json
{ "based_on": "v001", "saved_at": "2026-10-14T11:58:02+00:00", "data": { … } }
```

Номер версии — из имени файла, в конверте его нет.

## Поля

Текст всех полей, кроме подписей `label`, — **английский**: он уходит в промпт картинки (принцип 13). Подписи
`label` — по-русски, они только для экрана. У всех полей есть пустые значения по умолчанию: скелет из одного
`id` — годный черновик.

### Стиль — `Style` (`style/vNNN.json`)

Один на канал, одинаков для всех выпусков. Группы — как в артборде 12, слой «Стиль».

| Поле | Тип | Что это |
|---|---|---|
| `render` | str | «Рендер и материал»: техника изображения |
| `material` | str | фактура поверхностей |
| `processing` | str | обработка: кривая, контраст, резкость |
| `optics.focal` | str | «Оптика»: фокусное, высота камеры |
| `optics.depth` | str | глубина резкости |
| `optics.distortion` | str | дисторсия |
| `light.character` | str | «Свет»: характер, источники |
| `light.contrast` | str | контраст |
| `light.direction` | str | направление |
| `palette.rule` | str | «Палитра»: правило |
| `palette.swatches[]` | `{role: str, hex: "#RRGGBB"}` | образцы, 3–5 |
| `grain` | str | «Зерно и композиция»: зерно |
| `composition` | str | композиционные правила |
| `negative_global` | str[] | глобальный negative канала |

### Эпоха — `Period` (`periods/<id>/vNNN.json`)

Факты времени и места, переиспользуются между выпусками.

| Поле | Тип | Что это |
|---|---|---|
| `id` | str | `[a-z0-9][a-z0-9-]*`, совпадает с каталогом: `caribbean-1716` |
| `label` | str | подпись на экране, по-русски: «Карибы, 1716» |
| `region` | str | регион |
| `years` | `{from: int, to: int}` \| null | годы, `from ≤ to` |
| `palette_shift` | str[] | сдвиг палитры эпохи |
| `materials` | str[] | материалы |
| `light_sources` | str[] | источники света |
| `architecture` | str[] | архитектура и транспорт |
| `clothing` | str[] | одежда |
| `props` | str[] | предметы |
| `forbidden` | str[] | анахронизмы: идут в negative каждого кадра эпохи (L-007) |

### Персонаж — `Character` (`characters/<id>/vNNN.json`)

| Поле | Тип | Что это |
|---|---|---|
| `id` | str | `[a-z0-9][a-z0-9-]*`, совпадает с каталогом: `you` |
| `label` | str | имя на экране, по-русски |
| `nature.personality` | str | характер |
| `nature.posture` | str | осанка |
| `nature.manner` | str | манера |
| `nature.face` | str | черты лица — неизменяемы во всех обликах |
| `appearances[]` | `Appearance` | облики |

### Облик — `Appearance` (внутри персонажа)

| Поле | Тип | Что это |
|---|---|---|
| `id` | str | `<персонаж>@<облик>`: `you@powder-monkey-11`, префикс — id персонажа, без повторов |
| `label` | str | подпись на экране, по-русски |
| `period` | str | id эпохи облика |
| `age` | int \| null | полных лет, 0–120 |
| `build` | str | телосложение |
| `face` | str | уточнение к `nature.face` для этого облика: возраст, загар, борода |
| `hair` | str | волосы |
| `clothing` | str | одежда |
| `wear` | str | износ и повреждения |
| `props` | str[] | предметы облика |
| `negative_local` | str[] | negative облика |

## Черновик и публикация

1. `PUT …/draft` — черновик целиком. `based_on` берётся у прежнего черновика, а без него — последняя версия
   (правят то, что видят), без версий — `null`.
2. `POST …/draft?from=vNNN` — черновик из любой версии («Создать v004 из v002»). Если черновик уже есть — 409:
   его не затираем.
3. `POST …/publish` — правила публикации → `v<N+1>.json` → черновик удаляется. При отказе черновик остаётся как
   был, версия не пишется.
4. `DELETE …/draft` — сбросить черновик. Версии не трогаются.

**Правила публикации** (`publish_problems()`, отказ 409 со всеми нарушениями сразу):

| Слой | Правило |
|---|---|
| стиль | непустой `render`; 3–5 образцов палитры; у каждого образца есть `role` |
| эпоха | непустые `label` и `region`; есть `years`; `forbidden` — хотя бы одна позиция |
| персонаж | непустые `label` и `nature.face`; хотя бы один облик |
| облик | непустые `label` и `period` |
| все | нет кириллицы в полях промпта (всё, кроме `label`); нет пустых позиций в списках |
| все | черновик отличается от последней версии — иначе публиковать нечего |

## Ссылки из плана

Формат ссылок проверяет `CanonRef` (`models/director.py`), резолв — `canon_store`:

| Ссылка | Функция | Результат |
|---|---|---|
| `style/v003` | `resolve_style(paths, channel, ref)` | `Style` |
| `periods/caribbean-1716/v002` | `resolve_period(paths, channel, ref)` | `Period` |
| `characters/you/v004#captain-35` | `resolve_appearance(paths, channel, ref)` | `(Character, Appearance)`, облик `you@captain-35` |

Ссылка резолвится только в опубликованную версию, черновик ссылкой не достать. Канон выпуска (M5.2) считает
статусы ссылок плана по снимку канона канала — `docs/project_schema.md`, «Канон выпуска». Ошибка — `CanonRefError` (`.ref` —
исходная ссылка). Текст — фрагмент со строчной буквы, чтобы импорт плана (M5.2) мог приставить кадр:

- `стиль style/v003 не найден в каноне cursus`
- `эпоха periods/caribbean-1716/v002 не найдена в каноне cursus`
- `персонаж characters/you/v004 не найден в каноне cursus`
- `облик you@captain-35 не найден в characters/you/v004`
- `ссылка «periods/caribbean-1716/v1» не по формату periods/<эпоха>/vNNN`

## API

Префикс `/api/canon/{channel}`. Неизвестный канал — 404 «Канал … не найден» (`require_channel`). Слои:
`style`, `periods/{period_id}`, `characters/{character_id}`. Набор запросов у всех одинаковый.

| Запрос | Тело / параметры | Ответ |
|---|---|---|
| `GET /api/canon/{channel}` | — | `CanonSummary` |
| `GET …/{слой}` | `?version=vNNN`; без него — черновик, а без черновика — последняя версия | `StyleDoc` \| `PeriodDoc` \| `CharacterDoc` |
| `PUT …/{слой}/draft` | `Style` \| `Period` \| `Character` целиком | документ черновика, 200 |
| `POST …/{слой}/draft?from=vNNN` | — | документ черновика, 201 |
| `DELETE …/{слой}/draft` | — | 204 |
| `POST …/{слой}/publish` | — | документ новой версии, 201 |

Документ слоя: `{draft, version, based_on, updated_at, data}`. У черновика `draft: true`, `version: null`,
`updated_at` — `saved_at`. У версии `updated_at` — `published_at`.

`CanonSummary`:

```jsonc
{ "channel": "cursus",
  "style": { "versions": [{ "version": "v001", "based_on": null, "published_at": "…" }], "draft": false },
  "periods": [{ "id": "caribbean-1716", "label": "Карибы, 1716", "versions": […], "draft": true, "forbidden_count": 12 }],
  "characters": [{ "id": "you", "label": "Ты", "versions": […], "draft": false, "appearances_count": 3 }] }
```

Подпись и счётчики берутся из черновика, а без него — из последней версии. В список попадают только каталоги, где
есть черновик или версия.

## Нужно каналу

M5.2 (устав M5, решение 2). Планы ссылаются на эпохи и облики раньше, чем те появились в каноне: план из моста
получает заготовки `v001` (`docs/director_schema.md`, «Откуда версии»). «Нужно каналу» собирает такие id, из них
создаются скелеты. Логика — `pipeline/canon/episode_canon.py → canon_needed`, API — `api/canon.py`.

| Запрос | Ответ |
|---|---|
| `GET /api/canon/{channel}/needed` | `CanonNeeded` |
| `POST /api/canon/{channel}/needed/periods/{period_id}` | `PeriodDoc` черновика, 201 |
| `POST /api/canon/{channel}/needed/appearances/{appearance_id}` | `CharacterDoc` черновика персонажа, 201 |

**Что нужно.** Эпохи и облики из `canon_ref` **текущих** версий планов выпусков канала, у которых нет ни одной
опубликованной версии (у облика — ни одной версии персонажа, где он есть). Черновик не считается: эпоха с черновиком
в списке остаётся, с пометкой `draft: true`. Стиль в список не входит: он один на канал и виден в своём слое и в
каноне выпуска. Выпуски без плана пропускаются; битый файл одного выпуска — предупреждение в лог, как на доске.

```jsonc
{ "channel": "cursus",
  "periods": [{ "id": "venice-1570", "draft": false, "shots": 31,          // кадров во всех выпусках
                "episodes": [{ "id": "c09-galley", "title": "Галера", "shots": 31 }] }],
  "appearances": [{ "id": "you@comito-34", "draft": false, "shots": 12, "episodes": […],
                    "character_exists": true }] }   // персонаж есть — облик допишется в его черновик
```

Порядок — по id; выпуски — как на доске (по дате слота, без слота — в конце).

**Скелет** — черновик с одним id, остальные поля пустые (годный черновик, но не публикуемый):

- **эпоха** — `draft.json` с `{id}`, `based_on: null`;
- **облик** — в черновик персонажа `<персонаж>` дописывается `{id: <облик>}`. Черновика нет — он начинается с
  последней версии персонажа (`based_on` — она); персонажа нет — создаётся `{id, appearances: [{id}]}`.

Отказы — 409, ничего не пишется:
- `Эпоха caribbean-1716 уже опубликована (v001) — создавать её не нужно.`
- `У эпохи venice-1570 уже есть черновик — откройте его на экране «Канон» и опубликуйте.`
- `Облик you@captain-35 уже опубликован в characters/you/v001 — создавать его не нужно.`
- `Облик you@comito-34 уже есть в черновике персонажа you — откройте его на экране «Канон» и опубликуйте.`

id не по формату — 422 с текстами раздела «Ошибки»; неизвестный канал — 404.

## Ошибки

Одна фраза: что случилось и что сделать.

- **422 — форма.** Тело FastAPI: `detail[]` с `loc` и `msg`. Тексты — `PydanticCustomError` (L-022):
  - `id «Venice_1570» не годится — только строчные латинские буквы, цифры и дефис, например caribbean-1716.`
  - `id облика «captain-35» не годится — нужен вид <персонаж>@<облик>, например you@powder-monkey-11.`
  - `Облик otto@london-1666 не принадлежит персонажу you — id облика начинается с «you@».`
  - `Облик you@captain-35 повторяется — у каждого облика свой id.`
  - `Цвет «brown» не годится — нужен код #RRGGBB, например #2b2118.`
  - `Образцов палитры 6, а можно не больше 5 — уберите лишние.`
  - `Годы эпохи наоборот: from 1580 позже to 1570 — поменяйте их местами.`
  - `Возраст 300 вне 0–120 — укажите полных лет.`
  - `Версия «2» не годится — нужна вида v001.` (`?version=`, `?from=`)
  - `id «caribbean-1716» в теле не совпадает с адресом «venice-1570» — исправьте одно из двух.`

  Ошибки типов (строка вместо числа) и лишние поля — стандартные тексты pydantic.
- **409 — правило публикации или конфликт.** Тело `{"detail": "…"}`; несколько нарушений — через `\n`:
  - `Эпоха без запретов не публикуется — добавьте хотя бы один анахронизм.`
  - `Персонаж без обликов не публикуется — добавьте хотя бы один облик.`
  - `Поле light.direction написано по-русски — текст канона уходит в промпт картинки, пишите по-английски.`
  - `Пустая позиция в списке forbidden — заполните или удалите её.`
  - `Черновик эпохи caribbean-1716 не отличается от v001 — публиковать нечего, сбросьте черновик.`
  - `У эпохи caribbean-1716 уже есть черновик — опубликуйте или сбросьте его, потом создавайте черновик из v002.`
  - `У эпохи caribbean-1716 нет черновика — публиковать нечего.`
  - `Версия v002 эпохи caribbean-1716 уже есть — опубликованные версии не перезаписываются, обновите страницу.`
- **404 — нет сущности или версии.** Тело `{"detail": "…"}`:
  - `Эпохи venice-1570 в каноне cursus нет — создайте черновик.`
  - `У эпохи caribbean-1716 нет версии v009 — есть: v001, v002.`
  - `У эпохи caribbean-1716 нет черновика — сбрасывать нечего.`
